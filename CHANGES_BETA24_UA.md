# Pixora 1.0.14-beta.24 — сталі серії зміщень Speed Probe

Діагностика швидких кандидатів і запасу доповнена двома показниками:

- **Найдовша стала серія, перерізи** — максимальна кількість сусідніх однозначних перерізів з однаковим зміщенням. Зміна зміщення, прогалина або кілька можливих центрів переривають серію. Якщо однозначних перерізів немає, довжина дорівнює 0; це не доказ стабільності.
- **Частка переходів** — кількість змін зміщення / кількість сусідніх порівнюваних однозначних пар. Показується у відсотках. Якщо порівнюваних пар немає, показується «—»; 0% означає, що в наявних парах змін не було.

Показники збережені як необов'язкові `longestStableRun` та `transitionRate` у траєкторії `run.json`, `metrics.json` і журналу сесії. У старих beta.23 звітах залишаються попередні показники, але нові поля позначені «—». Дані заднім числом не обчислюються. Beta.22 звіт без траєкторії, як раніше, повідомляє про її відсутність.

Це опис положення підтвердженого ядра на знімку. Нові показники лише діагностичні: пороги стабільності не вводяться, PASS/FAIL не змінено. Ревізія `probe-spatial-envelope-v4`, калібрування, докази маршрутів, заморожені геометрія/RGB/допуск, таймер, затримки, планувальник, ETA, аудит і checkpoint залишаються як у beta.23. Сумісні докази v4 зберігаються.

Робочий код змінено лише в `ProbeOffsetTrajectory.cs`, `ProbeDiagnosticsPage.cs` та version props. Workflow залишився як у beta.23; запуск на GitHub і причина локальних CLR/Roslyn збоїв досі не підтверджені.

Перевірки охоплюють суцільну сталу лінію, одиничний перехід, зигзаг зі збереженим PASS, розрив серії через неоднозначність/прогалину, відсутні пари та сумісність старих JSON. Український і англійський інтерфейс перевіряються рендерингом без керування Rust. Новий живий тест не проводився.
