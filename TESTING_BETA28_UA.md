# Тест калібрування beta.28

1. Закрий стару Pixora, розпакуй ZIP окремо і перевір beta.28 у шапці. Потрібен .NET 8 Desktop Runtime x64.
2. У Rust відкрий чисте полотно. Збережи форму, масштаб, розташування та режим HEX/Palette. Перевір, що Canvas не включає дерев'яну рамку.
3. Round №3, набір 1/3/10/20, автоматичне калібрування. Якщо Size 1 слабкий, тест тепер має продовжити 3/10/20. Кожен успішний Size отримує саме 3/3 крапки; невдалий не зберігається. Запиши підсумок і повідомлення.
4. Якщо Size 1 не пройшов, перевір, що адаптив вимкнений, а список показує підтверджені інші Size. Очисти Canvas, вибери виміряний Size 3 на сторінці швидкості: просторове калібрування має бути доступним. Після нього очисти Canvas і виконай Speed Probe 3, якщо вистачає місця. Це не підтверджує Size 1.
5. Окремий тест на чистому Canvas: вибери «4 · Суцільний квадратний», у «Розміри для калібрування» лише «1». Збережи результат. Якщо успішний — очисти Canvas і відкалібруй потрібні більші Size для Square. Маски Round не застосовуються до Square.
6. При невдачі Square 1 не повторюй нескінченно й не примушуй адаптив: збережи PNG, metrics та `result.json`. У цьому випадку мінімальний пензель ще потребує виправлення.
7. Перемкни українську/англійську після часткової відмови: причина й підсумок мають перекладатися. Перевір ESC або втрату фокуса на окремому запуску: перерваний запуск не публікує нові маски.
8. Надішли відео та поточні config-csharp.json, session-csharp.jsonl і весь останній `brush-calibration/run-...` з `%LOCALAPPDATA%/Pixora`. Для Speed Probe також збережи його папку.

Four Blocks з аудитом перевіряй після підтвердження Size 1 для вибраної форми. Старі проблеми покриття не закриті самим частковим збереженням масок.
