# Pixora 1.0.14-beta.32 — простий старт і окремий розширений режим

## Основний шлях

За замовчуванням відкривається простий режим із трьома картками: «Зображення», «Полотно Rust», «Малювання». Зображення можна відкрити кнопкою або перетягнути. Налаштування Rust складається з двох виділень: внутрішнє полотно та палітра 4×16 або поле HEX. Скасування другого виділення зберігає попередні області.

У цьому режимі користувач вибирає в Rust суцільний квадратний пензель (4-й), Size 1, Interval 0.01, Opacity 1. Програма не натискає повзунки й не вимірює слід пензля. Видима підказка та розділ «Як налаштувати пензель» пояснюють ці значення. Це явний ручний вибір, а не підтверджене вимірювання.

Для старту достатньо зображення, збереженого контексту вікна Rust і вибраних кольорів. Вимірювання пензля, тест трьох HEX-кольорів, Speed Probe й аудит не є передумовами простого старту. HEX усе одно перевіряється зчитуванням поля при застосуванні кольору. Перевірки фокусу, геометрії та прав вводу збережені.

Кнопка «Малювати», пауза та зупинка закріплені внизу й не зникають при прокрутці налаштувань. У сайдбарі лише малювання, захоплення та два стани підготовки. Українські й англійські тексти мають явні переклади.

## Розширене малювання

Кнопка в шапці відкриває попередній розширений інтерфейс: adaptive, сім форм пензля, вимірювання Size, швидкість, порівняння палітр, аудит і дофарбування. Збережені налаштування не стираються при поверненні до простого режиму. Для простого плану створюється окрема копія налаштувань без експериментальних опцій; план, ETA та виконання використовують ту саму копію.

Кнопка калібрування пензля тепер доступна й при неповній підготовці: натискання веде до захоплення з поясненням, чого бракує. Спроба увімкнути adaptive без чинного Size 1 повертає перемикач у вимкнений стан та пояснює наступну дію. Критерії вимірювання, контрасту, повного ядра Probe та аудиту не послаблені.

## Журнал і межі перевірки

Доступний журнал цього ПК закінчується спробами beta.29: Round Size 1 відхилено з PeakDelta 68 і 66 при Required 80. Числові поля в тих спробах зчитували правильні значення. Нова версія прибирає залежність простого старту від цієї невдалої калібровки; слабкий фізичний слід не називається успішно виміряним. Логи з іншого ноутбука в цій перевірці відсутні.

Офлайн перевірки: 261 Core і 75 WPF, включно з реальним імпортом PNG, побудовою простого плану, HEX без захоплених повзунків, перемиканням режимів, поясненням adaptive та видимістю кнопки на висоті 620 px. Тести не виконують малювання у Rust. 100% прогрес у простому режимі означає завершення команд; покриття треба перевірити в грі. Існуючий звичайний маршрут руху миші збережено; нове прискорення не заявляється.
