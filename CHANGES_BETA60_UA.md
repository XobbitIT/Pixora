# Pixora beta.60 — мінімальний робочий Size 2

- Size 1 прибрано з робочого вибору, Adaptive, груп калібрування і швидкісних проб. Мінімальна деталізація у формі — 2 px; це окремий параметр від фізичного Size Rust. Типовий Size лишається 3.
- Старі налаштування Size 1 мігрують на 2. Архівні вимірювання зберігаються для діагностики, але не вибираються для малювання.
- Дофарбування потребує власної придатної виміряної маски Size >=2. За її відсутності воно зупиняється; радіусний fallback і синтетичні операції Size 1 прибрано.
- Максимум Adaptive у налаштуваннях приймає проміжні вимірювані розміри, які пропонує інтерфейс.
- План має нову ідентичність. Старий checkpoint не продовжуй; запусти новий START.

Контраст 80, RGB tolerance 12, перетин трьох масок, критерії Speed Probe і аудиту покриття не послаблювалися. Size 2 не гарантується лише тому, що він дозволений у формі: потрібне підтвердження його сліду.

Сьогоднішні журнали beta.59 показали збій читання HEX-повзунка, дві втрати фокуса, потім успішну підготовку. Повторне вимірювання Size 2 не підтвердило спільне непрозоре ядро. Координати Windows були правильні, але слід Rust зміщувався; причина цього за журналом не встановлена.

Офлайн-перевірки та новий живий прогін фіксуються окремо. Пакет локальний, без нового push у GitHub.

Під час живої перевірки виявлено проблему доступності вибору області: головне вікно приховане, а picker був відсутній у перемиканні вікон. Picker тепер показується як окреме вікно; логіка вибору координат не змінена.
