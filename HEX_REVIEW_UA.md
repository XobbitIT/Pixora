# Повторна перевірка HEX — 1.0.5 Preview

27 тестових сценаріїв пройшли. Ядро, тести й WPF-додаток скомпільовані Roslyn/.NET 8; залишається попередження CS1701 SkiaSharp.

Виправлено: читання поля більше не повертає перший довільний правильний за форматом HEX. Воно продовжує альтернативні способи виділення, поки не знайде очікуваний колір, або повертає останній неправильний результат для діагностики. Нормалізатор відхиляє зайвий # і часткові значення.

Кнопка тесту перевіряє FF3333, 12AC5F, 0397E2. Статус verified скидається до початку тесту і встановлюється лише після успіху всіх трьох кольорів. Додано перевірку фокуса та скасування тесту через 60 секунд. Лог відрізняє перевірку тексту від перевірки зразка кольору swatchVerified.

Нові регресійні тести: F3333F не приймається як FF3333; правильний пізніший результат приймається; null/частковий HEX/подвійний #/не-HEX відхиляються; RGB, порядок каналів і початкові нулі зберігаються для кольорів тесту, чорного й білого.

Введення SendInput та буфер обміну Rust у Linux не виконувались. Це перевірка логіки й компіляції, а не доказ виправлення самого ігрового поля. Тести не симулюють весь Unity UI. Якщо поле змінюється, але перевірка не проходить, потрібен новий hex_readback лог.

Оновлення: закрий CanvasForge. Скопіюй ОБИДВА файли з папки Update (CanvasForge.dll і CanvasForge.Core.dll) в наявну повну папку CanvasForge, замінивши їх. Залиш інші файли на місці. Запусти наявний CanvasForge.exe; заголовок має бути 1.0.5 Preview. Відкрий HEX-палітру Rust й натисни «Тест HEX (3 кольори)».

Папка Source містить сирцевий код; її не слід використовувати як папку запуску.
