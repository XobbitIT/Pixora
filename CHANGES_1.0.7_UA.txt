CanvasForge C# 1.0.7 Preview

Розпакуй усю папку, запусти CanvasForge.exe.

Прибрано захоплення Знаряддя (пензель/гумка/піпетка) та автоматичний клік по старих координатах знаряддя. Перед START вибери пензель вручну в Rust.

HEX тепер має окремі координати форм пензля, SIZE, INTERVAL, OPACITY.
1. Відкрий HEX-палітру в Rust.
2. У CanvasForge: Захоплення Rust → 3. Пензель і повзунки HEX.
3. Обведи ряд семи форм пензля, потім ПОВНІ зелені смуги SIZE, INTERVAL, OPACITY (від лівого до правого краю).
4. Вибери HEX Direct у програмі та натисни START, залишивши HEX-палітру відкритою в грі.
Поле HEX і його перевірка збережені. Повторно тестуй його після зміни положення поля.

Це окреме ручне калібрування для двох режимів, а не автоматичний пошук довільно переміщених елементів. Після зміни масштабу/розміру/розкладки редактора повтори відповідне захоплення.
31 тест пройшов; WPF-додаток скомпільований. Перевірка кліків у Rust потрібна на Windows.
