# Pixora 1.0.14-beta.56 — групова швидкість і корисні проходи

У палітрі більше не вибираються кольори, для яких виміряний план не має жодного штриха. У підсумку плану окремо показані доступні кольори Rust, кольори з командами й кольори без безпечних штрихів. Їхні ділянки залишаються видимими на карті пропусків.

У розділі «Тест швидкості» є «Перевірити швидкість для групи». Можна вибрати всі актуальні виміряні Size, 2/3/5/7/10/15/20, 3/10/20, 3/10, 20/30/40 або окремий Size. Група використовує актуальні просторові профілі повторно. Без профілю спочатку виконується повна просторова перевірка. Перед незалежними етапами й наступним Size потрібно очистити полотно та підтвердити продовження. Успішні маршрути зберігаються окремо; відмова наступного Size їх не стирає. Повторне просторове калібрування скидає лише маршрути відповідного Size. ESC або зміна контексту припиняє групу.

План більше не повторює штрих, суцільне ядро якого вже повністю покрили попередні штрихи цього кольору. Уже покриті кінці інших штрихів скорочуються. Оптимізація зберігає початкову маску покриття та відхиляється, якщо повний розклад після неї дорожчий за моделлю часу. М'які краї й можливий слід не використовуються як підтверджена заливка.

У вікні меж пензля наведений внесок кожного Size: штрихи, нове й повторне покриття за суцільним ядром. Вікно доступне також для плану без модельних пропусків. У журналі `measured_color_plan.strokeSavings` зберігається та сама діагностика; `palette_plan` містить фактичні й пропущені кольорові групи. Нові кнопки та основні повідомлення перекладені сімома мовами.

Пороги контрасту 80, RGB tolerance 12, перетин трьох відбитків, критерії Speed Probe й аудит незмінні. Змінені лише розклад кольорів, усунення надлишкових команд і організація групових перевірок. Файли первинного захоплення, кадрового аналізу Probe та аудиту покриття збігаються з beta.55.

Почни новий START: змінився ідентифікатор плану. Чинні вимірювання не потрібно видаляти. Старий checkpoint потребує нового запуску. Нова збірка проходить лише офлайн-тести; `inGameTest=false`, запуск Pixora.exe/ввід у Rust не виконувалися. Раніше надісланий локальний ZIP зберігає початковий маніфест до коміту.
