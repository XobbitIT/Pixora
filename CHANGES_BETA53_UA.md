# Pixora 1.0.14-beta.53 — міжнародний інтерфейс і перший запуск

- Вибір семи мов: українська, англійська, польська, німецька, французька, іспанська, російська. Новий словник спільний для сторінок, повідомлень, захоплення областей і порівняння палітр. Канонічні значення параметрів не перекладаються.
- При першому відкритті без зображення видно три кроки та потрібні дії. «Як почати» відкриває інструкцію повторно. Довідка не запускає введення в Rust. Відкриття зображення звільняє місце для прев’ю.
- Новий профіль користувача підбирає мову за Windows; збережена мова має пріоритет. Перемикання мов зберігається, а під час активного введення недоступне.
- Довгі написи кнопок переносяться. У п’яти нових мовах локалізовані основний шлях, кнопки, поля та інструкції захоплення; частина розширеної технічної діагностики лишається англійською. Переклад потребує перевірки носіями мов.
- Додано інструкцію старту сімома мовами, чернетки опису Steam і шаблон SteamPipe з Preview=1. Окремий Steam Content містить лише застосунок, runtime та публічну інструкцію, без Source/тестових DLL/приватних журналів.
- Core, planner, калібрувальні пороги, таймінги вводу й команди Painter збережені з beta.52. Цей реліз не змінює швидкість малювання чи методику ETA.

Перевірка: 391 Core / 144 WPF офлайн-перевірки та перевірки точних DLL архіву. Release — без попереджень і помилок. Живого тесту Rust, Steam-завантаження та нового пушу не виконувалося; `inGameTest=false`.
