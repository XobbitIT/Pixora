# Живий тест Pixora beta.27

1. Закрий стару Pixora. Розпакуй новий ZIP в окрему папку, запусти Pixora.exe і перевір beta.27 у шапці. Потрібен .NET 8 Desktop Runtime x64.
2. У Rust відкрий чисте полотно. Після зміни HEX/Palette повторно перевір захоплення полотна та controls: у межі Canvas не має потрапляти дерев'яна рамка. Не змінюй масштаб, розмір чи позицію Rust під час тесту.
3. Вибери круглу форму №3, Opacity 1. Проведи базове калібрування 1/3/10/20. Для кожного Size потрібні три успішні крапки. Якщо Size 1 знову відмовить, зафіксуй точний контраст у повідомленні; збережи `brush-calibration/run-...` разом із PNG і `*-metrics.json`. Невдалий набір не вважай відкаліброваним.
4. Перевір курсор після Size/Spacing/Opacity: він може відійти від controls для чистого знімка, але не має багаторазово повертатися між полем та попереднім штрихом. Наприкінці всього тесту має залишитись біля останньої намальованої дії. Коротко перевір ESC та втрату фокуса: скасування не має повертати курсор у гру.
5. Очисти Canvas. Просторове калібрування Size 1: усі шість ліній мають бути підтверджені. Після нього знову очисти Canvas.
6. Запусти Speed Probe Size 1. Не рухай мишу; записуй відео з FPS Rust. На ділянках очікуються пари: повільний контроль і швидка проба. Тест може тривати кілька хвилин. Для Size 3 повторюй лише після успіху Size 1 і достатнього місця.
7. Відкрий діагностику: вибери відхилений Candidate/Margin, перевір номер незалежного локального контролю, frozen RGB, потрібну ширину, кількість підтверджених перерізів. Перемкни «Контрастний слід (діагностика)». Суцільний синій слід із непідтвердженим кольором не означає PASS. Збережи весь `speed-probe/run-...`, навіть якщо маршрутів немає.
8. Лише з повними масками: очисти Canvas, Four Blocks, Adaptive ON, Round/max 20, аудит ON. Збережи first-pass і post-repair PNG, Missing/Unknown, реально використані Size та elapsed. Якщо аудит зупинив малювання, не називай його успішним. Почни новий START після очищення; старий RESUME не використовуй для зміненого плану.
9. Перемкни українську/англійську: нові повідомлення й діагностика мають перекладатися. Надішли відео та поточні `session-csharp.jsonl`, `config-csharp.json`, папки калібрування, Probe й coverage-audit з `%LOCALAPPDATA%/Pixora`.

Square, Auto Shape та Size 40/60/100 залиш до завершення базового тесту. Це послідовність для пошуку причини; PASS нового Speed Probe не замінює аудит фінального малюнка.
