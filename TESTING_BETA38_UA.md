# Pixora 1.0.14-beta.38 — живий тест

Розпакуй увесь архів в окрему папку й запусти Pixora.exe. У заголовку має бути beta.38. Налаштування користувача зберігаються; старі підтвердження придатні лише за незмінного контексту. Для калібрування відкрий чисте тестове полотно Rust. Записуй екран з обома програмами; не рухай мишу під час автоматичного вводу.

1. **Зображення й прев'ю.** Відкрий PNG/JPG; перевір відповідність оригіналу та результату. Зміни деталізацію й кількість кольорів. Після нового зображення не повинно залишатися плану попереднього. START недоступний під час завантаження.
2. **Повторний START та STOP.** На зображенні зі складним планом двічі натисни START. Має бути один запуск. Натисни STOP під час підготовки: після скасування малювання не має початися самостійно; повторний START має залишитися доступним після підготовки.
3. **Окремий пензель.** Вибери Square 4 / Size 1 на чистому полотні та відкалібруй. Перевір три повтори й знімки до/після. Сильний слід без спільного ядра має лишатися «Немає стабільного ядра»; слабкий слід не повинен ставати готовим. Після успішної бази окремо перевір 3/10/20; великі Size й інші форми — окремими чистими тестами.
4. **STOP кожної окремої перевірки.** Послідовно перевір: захоплення області, controls, пензель, просторове калібрування, Speed Probe. Для кожної дії натисни STOP у Pixora. Після повернення фокусу Rust можливі лише дії, які вже завершувалися перед скасуванням; новий етап чи відновлення controls починатися не повинні. Очисти тестові сліди перед повтором. У повноекранній грі можна використати ESC.
5. **Закриття під час перевірки.** На чистому тестовому полотні закрий Pixora під час окремого вимірювання пензля й окремо Speed Probe. Програма має скасувати роботу, звільнити кнопку миші та завершитися після очищення ресурсів. Після закриття нових штрихів бути не повинно.
6. **HEX-захоплення.** Перевір звичайне завершення всіх областей. В окремому повторі зміни розмір вікна Rust між виділеннями: координати старого кадру не повинні зберегтися як готові. Повтори захоплення в стабільному вікні.
7. **Speed Probe.** Лише після підтвердженого пензля виконай просторову перевірку та Speed Probe на чистих ділянках. Перевір окремі горизонтальні/вертикальні результати, повтори й запас затримки. Одного підтвердженого напрямку недостатньо для іншого; непідтверджені маршрути використовують звичайний ввід. Повтори STOP під час завершення тесту, щоб перевірити скасування відновлення controls.
8. **Повне малювання.** Очисти полотно; виконай Four Blocks із Palette, потім окремо HEX. Перевір усі суцільні блоки, правильні кольори й краї. Далі повтори з адаптивним пензлем і аудитом. 100% команд без аудиту не означає підтверджене покриття.
9. **PAUSE / RESUME / фокус.** Під час звичайного малювання натисни F6, повернися у Rust, продовж F6. Потім окремий запуск із STOP і RESUME за вимкненого аудиту та Opacity 1. Зміна зображення/плану має вимагати нового START. При ввімкненому аудиті після переривання потрібен новий запуск.
10. **Мова й діагностика.** Перемкни українську/англійську, перевір повідомлення скасування, причини калібрування й банер аудиту. Перезапусти програму; збережені знімки діагностики мають відкриватися знову.

Для фідбеку надішли відео, час кожної проблеми, режим Palette/HEX, форму/Size, версію з заголовка та журнал із папки даних Pixora. Не видаляй brush-calibration, speed-probe і coverage-audit після невдалого тесту. Необхідно розрізняти: команди завершено, калібрування підтверджено, покриття підтверджено аудитом.
