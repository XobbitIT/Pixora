# Beta.44 — запуск малювання та робочий Size

На записі 20:52 у beta.43 Round Size 3/10/20 підтверджені; о 20:56 повна перевірка завершена, чотири маршрути Speed Probe Size 3 збережені. Round Size 1 лишився слабким: останній повтор дав контраст 67 при необхідних 80. Малювання в журналі не почалось. Саме відсутність `start` не доводить, що кнопку не натиснули: запис створювався тільки після підготовки й відліку.

## Виправлено

- Підготовка ETA перед START кілька разів читала й перевіряла весь speed/spatial profile для кожної операції. На конфігурації користувача 1000 коротких операцій займали 12.037 с; після зміни — 0.020 с у тому самому offline benchmark. Це час підготовки, не прискорення вводу у Rust. Тимчасовий план часу використовує один незмінний перевірений snapshot. Живий ввід зберігає перевірку актуальності через `Resolve`.
- З’являються ранні `start_requested` і `start_preparing`; перший показує прийнятий/відхилений запуск. До відліку видно підготовку, працює STOP, перевіряється cancellation у циклі побудови часу. Автоматичне згортання переноситься на відлік.
- Раніше перевірявся Size 3, але Precision + Rapid ставили Size 1. Тепер є «Робочий розмір пензля (Size)», спільний для вводу, ETA й вибору перевіреного маршруту. Повна перевірка встановлює підтверджений Size. Деталізація зображення й профіль руху не перезаписують явний вибір.
- Для збереженого конфігу beta.43 у першій картці підготовки є кнопка «Використати підтверджений Size 3»; повторна повна перевірка не потрібна. Доступні лише актуальні вимірювання зі стабільним ядром.
- Повна перевірка після ручного вибору лише Size 1 також вимірює Size 3 на нових ділянках. Окреме калібрування Size 1 продовжує перевіряти тільки Size 1.
- Застарілий speed profile не блокує звичайний START: приватна конфігурація запуску використовує Stable від 20 мс, без швидкого пакета та Shift. Збережені налаштування не переписуються; UI пояснює fallback. Вимоги Adaptive й аудиту залишаються.

- Перемикання на HEX до захоплення його контролів більше не кидає виняток під час відображення робочого Size. Старі вимірювання палітри не використовуються як HEX-доказ.

## Межі

Це не новий PASS Size 1. Контраст 80, RGB tolerance 12, насичення першого відбитка та перетин трьох масок не змінені. Непідтверджений Size 1 не дозволяє Adaptive або ремонт країв. Size 3 ширший і може втратити тонкі деталі; числовий Size у Rust не дорівнює екранним px. Ідеальне покриття новим запуском у грі ще не підтверджено.

339 Core / 103 WPF перевірки: робочий Size, незалежність пресетів, відповідність ETA маршруту, велика підготовка, скасування, fallback і фактичний клік START без вводу у гру. Новий живий тест потрібен.
