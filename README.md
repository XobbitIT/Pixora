# Pixora

Automated raster painting assistant for Rust. Development build **1.0.14-beta.3** for Windows 10/11 x64.

- [Українська інструкція](README_UA.md)
- [Зміни цієї версії](CHANGES_1.0.14_UA.md)
- [Сценарії перевірки у Rust](TESTING_1.0.14_UA.md)

The Windows workflow runs the Core regression suite before publishing a self-contained portable build. Download its `Pixora_1.0.14-beta.3_Windows_x64` artifact, extract the entire archive, and run `Pixora.exe`.
