# Pixora 1.0.14-beta.47 — живий тест короткої підготовки

1. Закрий стару Pixora. Розпакуй весь новий архів в окрему папку. Перевір beta.47 у заголовку. Не змінюй масштаб чи роздільну здатність Rust після захоплення.
2. У Pixora відкрий «Налаштування» й натисни «Повільний ноутбук». Має бути «За смугою та відбитком», Stable, швидке перенесення вимкнене. Бюджети очікування можна подивитися в згорнутому блоці; для першого тесту лиши значення пресету.
3. У Rust відкрий чисте тестове полотно, обери інструмент пензля та HEX. У Pixora обери «Прямий HEX» і натисни «Підготувати до малювання».
4. Якщо областей ще немає, виділи полотно, HEX, ряд форм пензля, три зелені смуги разом із числами справа. У HEX більше немає кроку «Знаряддя». Далі не рухай мишу. ESC скасовує перевірку.
5. Очікуй чотири етапи: області, кольори, керування, один пензель. Типово вимірюється Size 3 тричі з додатковим контролем насичення. Spatial/Speed не повинні запускатися, форма не повинна раптом змінитися на Square. Невдалий відбиток залишається помилкою.
6. Якщо все підтверджено, очисти тестові крапки в Rust. Відкрий невелике зображення «Four Blocks», перевір обидва прев’ю та натисни «Почати». Очікуй чотири суцільні області правильних кольорів. Для першого проходу залиш Adaptive, аудит і прискорення вимкненими.
7. Повтори на «Edges»: перевір тонкі лінії та краї. Запиши фактичний час і зроби скриншот після завершення. У цьому проході немає автоматичного аудиту: 100% означає завершення команд, а не доказ піксельного покриття.
8. Окремо відкрий «Захоплення Rust» → «Окремі дії та розширена перевірка»: мають бути доступні перевірка керування, HEX, окремі смуги й повна перевірка. Перемкни мову й перевір ці назви та повідомлення.

Для відмови надішли новий `session-csharp.jsonl`, `config-csharp.json`, папку `controls-diagnostics` або останню папку `brush-calibration`. Візуальний режим пропускає лише копіювання чисел: `slider_check.strategy=visual_slider`, `numericReadback=false`; точний HEX залишається окремою перевіркою. Якщо смуга не розпізналася, важливий саме її збережений знімок.

За успіху базового тесту можна окремо відкалібрувати Size 10/20. Adaptive, просторові зміщення, швидкість і аудит перевіряються наступним проходом; Size 1 потрібний для Adaptive за попередніми правилами.
