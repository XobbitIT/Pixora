# Тест Pixora 1.0.14-beta.8 у Rust

## 1. Запуск

Повністю розпакуй `Pixora_1.0.14-beta.8_Windows_x64.zip` в окрему папку й запусти `Pixora.exe`. У шапці має бути **1.0.14-beta.8**. Runtime входить у portable-збірку. Старий checkpoint не підходить — потрібен новий START.

Захопи Canvas та потрібний режим кольорів. Перевір Size / Interval / Opacity: обводь смугу із запасом разом із числом справа. Вибери суцільний круглий або квадратний пензель. У **Пензель і швидкість → Пензель** виконай автоматичне калібрування 1 / 3 / 10 / 20, потім очисти Canvas.

## 2. Speed Probe — перший тест

1. Відкрий **Пензель і швидкість → Speed Probe і аудит**.
2. На чистому Canvas вибери **Size 3**, натисни **Запустити Speed Probe** і підтвердь пробні штрихи.
3. Не рухай мишу та камеру. ESC скасовує; втрата фокусу або F6 переривають тест. Якщо тест перервано, очисти Canvas перед повтором.
4. Потрібно до 62 чистих квадратних ділянок. Мінімальна сторона ділянки 64 px, для широкого пензля більше. Якщо місця бракує, програма пояснить це до вводу.
5. Розгорни **Результати за Size і напрямком**. Там зберігаються метод, вісь, безпечна затримка та випробувана довжина. Відсутній маршрут не пройшов перевірку. Повтори окремо для Size 1, 10 і 20, очищаючи Canvas перед кожним тестом.
6. Після тесту очисти Canvas. Pixora відновлює свої налаштовані Size/Interval/Opacity, якщо Rust лишився у фокусі. Тестовий колір лишається вибраним; початкові ручні значення гри не зчитуються як резервна копія.

Кандидати 32/20/12/8 мс мають по три повтори та додаткові три повтори із запасом. Успішний профіль автоматично вмикає **Використовувати підтверджений маршрут**. Його можна вимкнути для порівняння. Це порівняння затримок серед цих кандидатів, а не математично найвища можлива швидкість чи FPS-вимірювання.

## 3. Малювання із підтвердженим маршрутом

Вибери **Precision**, точні параметри та **Opacity 1**. Почни з чотирьох кольорових квадратів, нового START і вимкненого аудиту. Перевір суцільну заливку всередині, краї й правильність кольорів після завершення. Потім повтори із адаптивним пензлем на великих однорідних ділянках і дрібних деталях.

Зафіксуй реальний час із увімкненим і вимкненим підтвердженим маршрутом на однаковому чистому Canvas. Профіль не змінює деталізацію зображення. Неперевірені Size/осі та короткі штрихи лишаються на звичайному маршруті. Якщо налаштування змінилися, повтори тест або вимкни підтверджений маршрут.

## 4. Аудит і дофарбування

1. У вкладці Speed Probe увімкни **Перевіряти після кожного кольору**. Для першого тесту дофарбування залиш вимкненим.
2. На чистому Canvas виконай новий START для контрастних квадратів. Після кожного кольору очікується перевірка покриття.
3. Якщо аудит зупинився, прочитай кількість пропусків і невизначених пікселів та переглянь локальні PNG. Подібний колір фону, освітлення або рух сцени можуть зробити результат невизначеним; це не підтверджені пропуски.
4. Потім увімкни **Дофарбовувати підтверджені пропуски**, максимум **1** прохід, і повтори на чистому Canvas. Ремонт має залишатися всередині кольорової області. Крайові пропуски можуть вимагати нового тесту/START.
5. Перевір ESC під час руху, дофарбування та аудиту. У звичайному малюванні перевір F6 і повернення фокусу: миша й Shift повинні відпускатися, controls перевірятися повторно.

Аудит не сумісний із RESUME, бо потрібний початковий кадр кольорової групи. Для продовження checkpoint вимкни аудит і перевір сумісність плану; для перевіреної заливки виконай чистий START.

## 5. Стиль і фідбек

Перевір українську й English, вузьке та широке вікно, клавіатурний focus, поля з неправильними числами і підказку біля вимкненого START. Усі Size/Interval/Opacity та форма — у розділі пензля; параметри руху — на малюванні; аудит — у вкладці Speed Probe.

Надішли: скриншот результатів Speed Probe; результат квадратів після завершення; час перенесення; чи був adaptive/HEX/аудит/дофарбування. Журнал `session-csharp.jsonl` містить `speed_probe_trial`, `speed_probe_complete`, `coverage_audit`, `coverage_repair`. Локальні PNG: `%LOCALAPPDATA%/Pixora/speed-probe` та `%LOCALAPPDATA%/Pixora/coverage-audit`. Вони лишаються на комп’ютері та не завантажуються автоматично.
