# Тест Pixora 1.0.14-beta.5 у Rust

## Запуск і точні числа

1. Закрий стару Pixora. Розпакуй весь ZIP в окрему папку й запусти `Pixora.exe`; заголовок має містити `1.0.14-beta.5`.
2. У Rust відкрий редактор картини. Якщо захоплення beta.3 актуальне, його можна використати. Якщо числа чи форми змістилися, повтори налаштування Rust.
3. Для кожного повзунка обведи один повний ряд разом із числом справа та запасом навколо. Перевір зелені рамки, натисни Enter. Ручні Size anchors не потрібні й не використовуються.
4. Спочатку вимкни адаптивний пензель. Вибери `Stable / Safe / Precision / Opacity 1`. У Rust вручну постав Size 20, Interval 0.33, Opacity 0.5.
5. «Захоплення Rust» → «Числові поля Size / Interval / Opacity» → «Перевірити Rust controls». Очікується Size **1**, Interval **0.01**, Opacity **1**. Pixora вводить числа й копіює їх назад для підтвердження. Для Max Speed ціль Size 3.

## Повтор після відео 20:06

Введення Size 1.00, Interval 0.01 та Opacity 1.00 вже підтверджене журналом beta.4. Основна перевірка beta.5 — чи калібрування проходить першу маленьку крапку й вимірює всі чотири розміри. Очисти попередні тестові крапки перед повтором.

## Адаптивний режим — одна кнопка

1. Відкрий **чистий Canvas** в Rust.
2. У Pixora натисни **«Адаптивний режим»** зліва. У секції **1. Підготовка** має бути зелена/позитивна готовність захоплення. Обери суцільний круглий або квадратний пензель.
3. У секції **2. Автоматичне калібрування** натисни **«Калібрувати автоматично»** й підтвердь тест. Програма сама вибере контрастний колір і виконає 1 → 3 → 10 → 20. Не рухай мишу; ESC скасовує.
4. На Canvas мають з’явитися **чотири крапки різних розмірів**. Після повернення статус має бути **«Калібрування актуальне»**, а в «Виміряні розміри пензля» — чотири результати.
5. У секції **3. Адаптивне малювання** перемикач має бути ввімкнений автоматично. Обери максимальний Size **10** для першої спроби, потім порівняй із **20**.
6. **Очисти Canvas**, перейди до малювання, завантаж `Pixora_Test_4_Colors.png` і зроби новий START. Очікуються чотири кольорові квадрати без виходу широких штрихів за межі.
7. Натисни F6, вручну зміни три числа, повернись до редактора й F6. Програма має відновити та перевірити числа перед продовженням.

Зміна Canvas, режиму кольорів або форми має показати потребу повторного калібрування. Переміщення того самого вікна Rust до START підтримується; зміна DPI/розміру вікна потребує нового захоплення.

## Якщо щось не працює

- Зафіксуй, на якому Size зупинилося калібрування, чи з’явилася крапка та чи змінилося число.
- Додай відео саме від натискання «Калібрувати автоматично» до результату.
- Корисні файли: `%LOCALAPPDATA%\Pixora\config-csharp.json`, `session-csharp.jsonl` та `brush-calibration\failed-before.png` / `failed-after.png`, якщо вони створилися.
- У журналі `control_readback` показує скопійоване число, `slider_check` — підтвердження числа й смуги, `brush_measurement` — виміряну крапку.

82 Core тестів і 5 WPF перевірок перевіряють алгоритми та інтерфейс. Реальний результат малювання й прийняття вводу перевіряються окремо у грі.
