# Перевірка Pixora 1.0.14-beta.2 у Rust

## Підготовка

1. Закрий попередню Pixora. Збережи копію `%LOCALAPPDATA%\Pixora`.
2. Розпакуй весь portable-архів в окрему папку й запусти `Pixora.exe`. У заголовку має бути `1.0.14-beta.2`.
3. Відкрий редактор Rust. Повторно захопи Canvas, палітру/Quick Colors та controls. Кожен повзунок обводь **разом із числовим полем справа**, не захоплюючи сусіднього рядка. Старі ручні Size anchors після нового захоплення Size очищуються.
4. Для HEX окремо захопи поле й HEX-controls. Зразок активного кольору опційний; захоплюй центральну однорідну ділянку без тексту та рамки. Для Rust Palette виконай це в режимі Rust Palette, для HEX — в HEX Direct.
5. Почни зі `Stable / Safe / Precision / Opacity 1`, adaptive brush вимкни. Використовуй новий START.

Для відтворення точних параметрів відео: Canvas 1044×1041, cell_px 8, Max Speed, smart/fill_subject, адаптивний пензель вимкнено. Тест із чотирма кольорами створює 504 штрихи в обох режимах, якщо палітра містить ці кольори. Для Safe чи іншої геометрії кількість буде іншою.

## Координати та додаткові режими

- Після успішного базового тесту перемісти вікно Rust до START без зміни розміру/DPI. Перевір палітру та HEX, потім повторне захоплення лише Canvas.
- Зміни розмір/DPI: старе калібрування має вимагати повного захоплення. Переміщення під час малювання має зупинити ввід.
- Калібруй adaptive brush на чистому Canvas від 240×240 px із контрастним кольором, очисти Canvas і перевір адаптивне малювання. Ручні Size anchors для HEX захоплюються окремо.
- Зміна внутрішнього масштабу UI Rust потребує нового захоплення навіть за незмінних Windows DPI та розміру вікна.

## Фідбек

Найцінніші результати зараз: **1 → 2 → 3 → 4 → 5**. Для проблеми вкажи номер тесту, режим, двигун, профіль швидкості та adaptive on/off. Додай скрин/відео, конфіг і журнал `%LOCALAPPDATA%\Pixora\session-csharp.jsonl` від відповідної спроби.

У журналі корисні `slider_check`, `slider`, `reprime`, `palette`, `hex`, `hex_readback`. `verified: true` означає перевірені controls або зразок кольору. Завершення з `resultVerified: false` повідомляє лише про виконання команд; оцінюй результат у грі.
