# Pixora 1.0.14-beta.44 — короткий тест реального запуску

1. Закрий стару Pixora, розархівуй beta.44 окремо й запусти. Поточні налаштування можна зберегти.
2. Відкрий зображення Four Blocks або невелику картинку. На сторінці «Малювання» у першій картці підготовки натисни «Використати підтверджений Size 3», якщо вона видима. Робочий Size має бути 3.
3. Не повторюй всю підготовку: останні Size 3/10/20 і швидкість у цій конфігурації вже підтверджені. Якщо захоплення змінилося, UI повідомить, що використовується звичайний стабільний ввід.
4. Очисти полотно Rust, лиши HEX-палітру відкритою й натисни саме помаранчеву кнопку «Почати» у Pixora. Має з’явитися підготовка, потім відлік. F6 ставить на паузу вже запущений процес.
5. Перевір, що Size у Rust став 3, зміни кольорів відбуваються й зображення реально малюється. Одночасно не рухай мишу. ESC/STOP мають зупиняти процес; F6 — пауза/продовження.
6. Якщо старт знову зависає, надішли `session-csharp.jsonl`: ранні `start_requested`/`start_preparing` тепер розрізняють натискання, підготовку та ввід.

Size 1 поки не вважай робочим. Його повторне вимірювання — окремий тест; воно не потрібне, щоб перевірити малювання з Size 3. Adaptive й audit залиш вимкненими для цього запуску. Ширший пензель не підтверджує точність деталей 1 px.
