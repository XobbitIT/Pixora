# Pixora 1.0.14-beta.58 — підготовка одного пензля та відновлення керування

- Основна кнопка «Підготувати до малювання» виконує Capture → Colors → Controls → Brush для одного робочого Size. Size 1, інші розміри, Spatial та Speed Probe не є обов’язковими. Повна послідовність доступна в окремих налаштуваннях захоплення.
- Початкова підготовка використовує суцільний круглий або квадратний пензель. Якщо була вибрана м’яка/текстурна форма, для цього проходу вибирається суцільний круглий. Ручні дослідження інших форм залишаються доступними.
- Перед перевіркою керування та калібруванням програма повторно знаходить групу трьох повзунків і ряд семи пензлів у захопленій панелі Rust. Автоматичне відновлення приймає лише повну геометрію; неоднозначний результат не породжує координат. Відновлення не залежить від ліміту 4/8/16/64 кольорів плану. Змінена геометрія робить попередні виміри застарілими.
- Нове підтвердження кольору до й після крапки: свіжий HEX readback або два кадри активного зразка палітри. Це дозволяє виміряти непрозоре локальне ядро, коли Rust освітлює чорний синюватим відтінком. Це не доказ абсолютного RGB намальованого пікселя. Без незалежного підтвердження діє попередня сувора перевірка нейтрального відтінку.
- Контраст 80, RGB tolerance 12, контроль насичення, напрям зміни кольору й перетин трьох масок не знижені. Пікселі, додані контрольним нанесенням, не стають ядром першого відбитка. Старі допустимі профілі сумісні; повторний тест відкликає підтвердження тільки розмірів цієї форми, які перевіряються.
- Speed Probe має додатковий компактний варіант розміщення. У відтвореній геометрії 1039 × 1044 px він вміщує всі 62 незалежні ділянки Size 20, замість відмови на 132 × 132 px. Зберігаються три повтори, перевірка запасу й окремі фізичні сліди контрольної та швидкої ліній. Shift обмежується фактично перевіреною коротшою довжиною; приріст швидкості не гарантовано.
- Нові повідомлення та інструкція першого запуску перекладені сімома мовами.

Перевірка: 470 Core / 169 WPF, включно з 84 макетами мов/DPI/станів. Release: 0 warnings / 0 errors. Живий запуск нової beta.58 у Rust ще не виконаний. Pixora.exe, SendInput і native clipboard smoke під час перевірок не запускалися.
