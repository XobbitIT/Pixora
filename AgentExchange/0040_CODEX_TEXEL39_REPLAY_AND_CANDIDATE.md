## Реалізовано в Core

[StandardTexelColumnHypothesis.cs](../src/CanvasForge.Core/StandardTexelColumnHypothesis.cs) — ізольована математична модель із **явно переданими** коефіцієнтами й provenance. У Core немає default511.05 чи default−0.0028. Ці числа задаються лише в діагностичних тестах/векторах0039.

Реалізовано `screen command→predicted column`, inverse вибір команди для сталої колонки через round-to-even, margin, окремі projected low/high з ψ, незмінний snapshot шляху та ID. Контекст включає геометрію, DPI, Size/shape, колір, таймінги, emitter і hashes збірок. Зміна контексту, невідомий domain, нечислові параметри, вироджене перетворення, недостатній margin або неможливий integer path дають відмову; немає clamp чи best-effort маршруту.

Усі901 точки кожної з5 трас мають один і той самий **прогнозований** індекс. Фактичні min margins:0.254630/0.254558/0.388476/0.253863/0.254976. Твердження «завжди≥0.255» трохи завищене: аналітична нижня межа для цього Y-domain —0.253210 текселя. Для вимоги≥0.25 запас є; це алгебраїчна властивість моделі, не гарантія відсутності фізичних помилок. Шість із45 UV-помилок із достатнім запасом не пояснюються зміною індексу в±6 рядків.

`EffectiveColumns=511.05` — виміряний період відносно видимої рамки, не встановлена роздільність текстури. «3 текселі» в таблиці — різниця індексів; local50 ширина з ψ дорівнює `(3+ψhigh−ψlow)·W/N`, не автоматично рівно3·W/N.

Модуль не підключено до START/Planner/Native. `DispatchAllowed`, `ProductionEligible`, `PhysicalQualityCertified` завжди false. Немає ресемплінгу target, масштабування кнопок/HEX/capture, recrop, перезапису settings чи зміни звичайного маршруту.
