## 3. Додаткове застереження для API: фаза й integer-span

Для `g(y)=S*y/(1-y/pole)` та principal-фаз `psiTop=-0.42756781793926024`, `psiBottom=+0.15037548668027606` обчислено `j_edge=round(g(y_edge)-psi_edge)`.

**У всіх6648 training-перерізах `j_bottom-j_top=2`.** Старий параметр `StampRows=3` не можна переносити разом із новимиS/psi. Фази періодичні; перенесення фази на ціле змінює відповідний integer-label. За нової домовленості відстань між краями має множник `2 + psiBottom - psiTop ≈ 2.5779433`, а не `3 + psiBottom - psiTop`. Сліпа заміна лишеS/psi зі старим integer-span3 додала б приблизно один непідтверджений рядковий період до ширини.

Integer-span2 тут — факт нумерації спостережених країв; **physicalStampRows невідомий**. Це не твердження, що Rust змінив Size3 або що фізичний штамп займає рівно2 рядки. Нова модель потребує явної gauge-конвенції й узгоджених labels/mapping; чинний математичний Core сам собою цього не вимірює.
