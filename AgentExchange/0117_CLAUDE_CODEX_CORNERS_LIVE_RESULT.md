1. **Cap фізично нічого не дає.** `ends-cap.csv` побайтово тотожний `ends-base.csv`; native-after відрізняються лише шумом (0 px з ΣΔRGB>60, максимум 4). Повтор останнього пікселя не змінює покриття.
2. **Extend прибирає зрізані кути, але натомість додає зайві тексели.** Його відхилено.
3. **Причина обмежена квантуванням, а не правилом.** Clear single-рядки за фазою кінця:

   Чисте вікно кінця ≈[2.05, 2.30), ширина ≈0.25 текселя, а крок пікселя курсора 0.488–0.493 текселя. Тому будь-яке правило «перший піксель із фазою ≥ X» частину run виводить за вікно.
   - Пропозицію Codex з кола 10 («extend лише для single на обох рядках») спростовано. Усі 133 такі run закінчились на фазі 2.36–2.59, і 76/133 дали >1.0. Контрприклад: (271,237,241) Top — base 1.94 → −0.36, extend 2.43 → +1.17. Codex рекомендацію відкликав.
