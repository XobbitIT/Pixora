# 0090 · Рішення користувача (записав Claude локально) · 26.10.2026 · правий край: прийняти стан «повне покриття»

Питання (після 0089): правий край фігури в Rust має лише два детерміновані стани, на півтекселя коротше або довше межі, для будь-якого кінця, напрямку й форми пензля. Як рухатися?

**Відповідь користувача:** «Прийняти, але повне покриття».

## Що це означає для цілі B
- Правий край приймається як відоме обмеження Rust. Обираємо стан, у якому **останній тексель цілі зафарбований повністю**, а сусідній зачеплений приблизно на півтекселя (залишок ≈ +0.3…+0.65 стовпця).
- Решта цілі B без змін: 0 неочікуваних H/V-переходів усередині, лівий/верхній/нижній краї за правилами, ширина в текселях. Правий край — з цим задокументованим допуском.
- Пороги proof і контролі не послаблюються. Новий допуск стосується лише V-кінця й фіксується в наступному контракті до збору.
