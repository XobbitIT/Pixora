# Pixora 1.0.14-beta.33 — тест у Rust

## 1. Початок

1. Закрий попередню Pixora, розпакуй весь архів у нову папку та запусти Pixora.exe. У шапці має бути beta.33. Конфіг у %LOCALAPPDATA%/Pixora збережеться.
2. Переконайся, що перемикача Простий/Розширений немає, а Малювання / Захоплення Rust / Пензель / Тест швидкості / Налаштування доступні.
3. Відкрий чисте тестове полотно Rust; збереження/скасування картини залишається твоєю дією. Вибери в Pixora той самий Palette або HEX, що зараз відкритий у грі.
4. На «Пензель» залиш 1/3/10/20; для першого запуску Speed Size 3. Відкрий або перетягни просту картинку Four Blocks.

## 2. Одна кнопка

1. Натисни «Налаштувати та перевірити все» в Малюванні або Захопленні Rust. Підтверди початкове попередження один раз. Більше підтверджень між етапами бути не повинно.
2. Якщо є майстер, виділи сім областей: полотно; Palette 4×16 або шість HEX-цифр; ряд трьох інструментів; ряд семи форм; смугу Size із числом; смугу Interval із числом; смугу Opacity із числом. Виділяй із запасом. Якщо захоплення актуальне, повторних виділень немає.
3. Не рухай мишу. Запиши відео всього проходу: кольори → числові поля → крапки пензля → шість повільних просторових ліній → Speed Probe із повільними сусідніми контролями.
4. Якщо Round Size 1 відхилено, має автоматично вибратися Square №4 і з’явитися нова група крапок на іншому місці. Старі FAIL-и Round не мають стати PASS. Якщо Square теж відхилено — послідовність зупиняється, швидкі проби не виконуються, видно причину.
5. Після успіху подивись шість результатів у Захопленні Rust. У деталях пензля видно форму й нові Size; простір/швидкість вказують свій один Size. Інші розміри не мають називатися перевіреними за швидкістю.
6. Якщо площі бракує, повідомлення має пояснювати це. Скористайся окремими кнопками, очищаючи полотно між діями; програма не повинна малювати поверх зайнятих тестових ділянок.
7. Після завершення або помилки очисти тестові крапки й лінії. Не запускай малюнок на неочищеному тестовому полотні.

## 3. Окремі функції та скасування

1. На чистому полотні окремо запусти Square Size 1. Перевір три незалежні вимірювання, збереження лише 3/3 і детальну причину відмови при невдачі.
2. Перевір окремі кнопки Size / Interval / Opacity, HEX-тест, захоплення інструментів і форм, просторовий тест та Speed Probe. Зміна однієї функції не має приховувати інші.
3. На повторному запуску повної перевірки натисни ESC під час крапок або ліній. Наступні етапи мають залишитися «очікує», миша/Shift — відпущені. Очисти полотно.
4. Перевір «Зупинити перевірку» у шапці коли Pixora видима, та закриття вікна під час активної перевірки. Не повинно залишитися фонового вводу після закриття.
5. Зміни мову UA → EN → UA після завершення/помилки. Кнопки, етапи, пояснення й збережені результати мають бути читабельні відповідною мовою.

## 4. Реальне малювання

1. Після успішної підготовки та очищення натисни «Почати» на Four Blocks. Усі чотири ділянки повинні заповнитися, а не перетворитися на вертикальні лінії.
2. Перевір Palette та HEX окремо; для іншого режиму потрібні його області й актуальна калібровка. Не перенось докази одного режиму на інший.
3. На складнішому зображенні перевір краї, зміни кольорів, адаптивні Size, PAUSE/F6, STOP/ESC. Для наступного Size швидкість перевіряється окремо.
4. Аудит покриття, якщо увімкнений, має спиратися на фактичний знімок. «Перевірки завершено» не повинно означати, що покриття картинки вже підтверджене.

Надішли відео, %LOCALAPPDATA%/Pixora/session-csharp.jsonl і config-csharp.json, папки brush-calibration та speed-probe/діагностику відповідного запуску. Вкажи, який етап зупинився і чи Square Size 1 пройшов. Офлайн тести нової збірки не замінюють цей живий прохід.
