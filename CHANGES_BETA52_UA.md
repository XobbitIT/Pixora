# Pixora 1.0.14-beta.52 — універсальний інтерфейс

- Із підготовки прибрано вибір «Звичайний ПК / Повільний ноутбук». Основний шлях: відкрити зображення → підготувати Rust → почати малювання. Кнопка автоматичної підготовки та її чотири етапи збережені.
- Додаткові способи підтвердження знаходяться в закритій секції «Налаштування → Сумісність з Rust». Назви описують дію: «Зчитування чисел» та «Візуальна перевірка». Візуальний профіль зберігає довші очікування і стабільний ввід; він доступний на будь-якому пристрої.
- Налаштування з попередньої версії зберігаються. Відкриття сторінок не застосовує профіль автоматично. Ручні таймінги лишаються доступними в додатковій секції.
- Кнопка діагностики керування видима лише за наявності збереженого знімка відмови. Вона відкриває знімок і пояснює причину.
- Підказка готовності показує перший потрібний крок: спочатку зображення, потім області Rust і перевірки. Відсутність зображення більше не приховується повідомленням про наступне калібрування. Усі умови блокування малювання збережені.
- Назва профілю «Ілюстрації та контури» охоплює різні типи зображень. Параметри самого профілю збережені.
- Прибрано твердження про фіксовані «поточні 20 мс» та повідомлення про майбутню розробницьку перевірку у вікні «Про програму». Українська й англійська версії мають однакову структуру.

Офлайн-перевірка: 391 Core / 134 WPF. Release: 0 попереджень / 0 помилок. Повторні перевірки виконуються також на DLL із готового пакета. Формули малювання, Core, критерії калібрування, транспорт вводу, затримки та ETA не змінено порівняно з beta.51.

Збірка локальна, на основі Git commit `3a60cc8f94ee242f096e59b1e444bf7a696c28ef` із попередніми локальними змінами beta.51. Нового пушу, CI або живого тесту beta.52 немає. `inGameTest=false`. Pixora.exe і ввід у Rust під час цих перевірок не запускалися.
