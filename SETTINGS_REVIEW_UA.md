# Перевірка налаштувань CanvasForge 1.0.9

Ліміт палітри Rust (`max_colors`) та ліміт HEX (`hex_max_colors`) — різні параметри.
Rust використовує лише захоплені кольори. Значення 96 не створює нових кольорів,
якщо в захопленій палітрі їх менше. HEX може створювати до 256 кольорів.
Обидва ліміти перенесені в одну секцію; видно лише ліміт активного режиму.

## Профілі

Профіль застосовується окремою кнопкою. Вибір назви сам по собі не застосовує його.
Після застосування всі параметри можна змінювати вручну; профіль не переписує їх
до наступного натискання кнопки.

| Профіль | Деталізація | Розмиття | Згладжування | Мін. область | Median cleanup |
| --- | ---: | ---: | ---: | ---: | --- |
| Anime / Line Art | 5 | 0.02 | 0 | 1 | Ні |
| Photo | 6 | 0.18 | 0 | 1 | Ні |
| Pixel Art | 4 | 0 | 0 | 1 | Ні |
| Fast | 8 | 0.45 | 1 | 2 | Так |

Профілі також задають smart-розміщення, вимикають dithering, видалення фону й
fill subject, встановлюють background preserve та ліміт палітри 64 або 96.
Custom нічого не застосовує. «Рекомендовано» задає деталізацію 3 та Rapid.
Профіль Pixel Art не вимикає поточні edge preserve/skin assist автоматично.

## Розширені параметри

Перевірено шлях від елементів налаштувань до коду Planner, ImageProcessing,
Painter, Capture, StrokeTiming та RenderPlan. Повністю непідключених параметрів
серед показаних не знайдено. Але не всі параметри діють одночасно:

| Параметр | Умова дії |
| --- | --- |
| Ліміт Rust / HEX | Лише відповідний режим кольорів |
| Auto threshold | Ліміт кольорів Auto |
| Background fill | Background mode = auto та відсутні прозорі клітинки |
| Coverage pitch | Coverage = Fast |
| Shift-line і його швидкість | Fast, увімкнено Shift-line, лінія достатньої довжини |
| Ручний Size | Вимкнено precision controls або Fast; також вимкнено auto brush size |
| Ручний Interval | Вимкнено precision controls або Fast; інакше 0.01 |
| Opacity | За ввімкненої fixed opacity; інакше 1 |
| Round/Square | Резервний вибір, якщо немає доступного слота захопленого ряду форм |
| Допуск і повтори controls | Увімкнено verify controls |
| Затримка зміни кольору | Rust Palette |
| HEX затримка, перевірка, повтори | HEX Direct |
| Допуск HEX swatch | Увімкнено перевірку та захоплено swatch |
| Матеріал прев’ю | Є збережений знімок Canvas |
| Автопоказ вставки | Завершено захоплення Canvas і є план |

Мінімальні фактичні затримки: HEX 180 мс, відпускання звичайного кліку 40 мс,
повторний клік 40 мс, input frame 16 мс. Менше значення у деяких полях не
прискорює ці дії. Cycle delay застосовується, лише якщо перевищує input frame.
Sequence delay використовується при налаштуванні повзунків, а не кожному штриху.

Виправлено негайне оновлення прев’ю після перемикання його параметрів і оновлення
оцінки часу після зміни числових налаштувань. Автопоказ вставки перейменовано
відповідно до фактичної поведінки: після захоплення Canvas.

## Межі перевірки

33 автоматичні тести пройшли. Збірка WPF пройшла з попереднім попередженням
CS1701 щодо сумісності посилання SkiaSharp/System.Runtime. Код керування
вводом, вибору HEX та геометрії штрихів не змінювався. Перевірка умов у коді
не замінює перевірки всіх повзунків у живій грі. Windows GUI тут не запускався.
