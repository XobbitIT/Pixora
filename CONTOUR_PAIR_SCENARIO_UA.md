# Один порівняльний запуск корекції

1. Розпакуй Pixora_Contour_Pilot_2_Windows_x64.zip у нову папку. Закрий інші копії Pixora.
2. Відкрий той самий редактор Rust і повністю очисти Canvas. Залиш вікно/zoom такими, як під час Size3_Repeats. Interval0.01 /Opacity1.00 — вручну, без захоплення цих полів.
3. Запусти **Run_Contour_Pair.cmd**. Після Enter за10 секунд повернись до Rust. Програма сама намалює п'ять контрольних смуг і збере файли.
4. Після DATA_COLLECTED очисти полотно повністю. Не міняй захоплення/вікно. У скрипті натисни Enter для candidate й повернись у Rust за10 секунд. Програма виконає ті самі п'ять смуг новими траєкторіями.
5. Залиш папку Contour_Pair на місці й повідом її шлях. Важливі обидва прогони, включно з файлами невдалої спроби.

Це експериментальна корекція фізичних країв. Вона ще не ввімкнена у звичайному GUI. **Pixora.exe без аргументів запускає попереднє малювання — для цього порівняння потрібен CMD вище.**

Скрипт не продовжить після невдалого control. Папки спроб не перезаписуються; повтор тієї самої спроби заборонено. Неочищений Canvas candidate блокується до paint. Якщо guard відмовив, збережи файли, не скидай налаштування для обходу.
