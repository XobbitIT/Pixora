# Pixora 1.0.14-beta.48 — робочий Size від 3

Локальна тестова збірка; без нового пушу GitHub. Pixora.exe і живий Rust під час перевірок не запускалися; `inGameTest=false`.

- Звичайний робочий Size — типово 3. Size 1 і «За профілем руху» прибрані зі списку робочих пензлів. Ручний Size має мінімум 3; автоматичний розмір звичайного малювання також не опускається нижче 3.
- Основне калібрування починається з Size 3; група — 3/10/20. Повна автоматична перевірка більше не додає Size 1. Окремий тест швидкості обирає Size від 3, без послаблення вимог до чистої тестової площі.
- Size 1 залишений у секції «Адаптивне малювання»: окрема кнопка «Перевірити Size 1 для Adaptive» та його діагностичний стан. Основна картка показує підтвердження робочого Size, а статус Size 1 — лише секція Adaptive. Внутрішній виконавець цього тесту далі встановлює саме Size 1. Adaptive вимагає актуального стабільного ядра Size 1 за попередніми правилами.
- Старі звичайні налаштування Size 1 / Profile переходять на 3. Збережені відбитки Size 1 не видаляються. Успішне звичайне калібрування не вмикає Adaptive автоматично.
- «Чітко · 1 px» залишається: це крок сітки зображення, окремий від значення Size у Rust. Підказка пояснює різницю. Size 3 може гірше передавати найтонші деталі; його стабільність у Rust потрібно підтвердити живим тестом.

365 Core / 116 WPF офлайн-перевірок, включно з міграцією, автоматичним розміром, окремим внутрішнім калібруванням Size 1 та українським/англійським інтерфейсом. Release: 0 warnings / 0 errors. Готові DLL перевіряються повторно у пакеті.

Контраст 80, RGB tolerance 12, вимірювання/перетин масок, формули planner, критерії Speed Probe і аудит покриття не змінені. Невдалі виміри Size 1 не доводять, що Rust принципово не підтримує цей Size.
