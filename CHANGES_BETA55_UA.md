# Pixora 1.0.14-beta.55 — комбіновані розміри та вартість маршрутів

Відео 09.10 і журнал beta.54 підтвердили: адаптивний режим міг створити більше роботи, ніж звичайний. На гербі звичайний Size 3 дав 3 484 штрихи, широкий план — 5 567, а модельне покриття зросло лише з 535 291 до 540 291 px. У виміряного Size 20 стабільне ядро було 3 × 21 px при можливому сліді 40 × 39 px. Значення Size у Rust не дорівнює діаметру гарантованої фарби.

Зміни:

- Спільна перевірка Size 2/3/5/7/10/15/20. Кожен Size отримує три незалежні відбитки. У повній підготовці стандартний вибір тепер запускає цю групу; вручну вибрану групу збережено. Size 3 залишається звичайним дефолтом, Size 1 — необов'язковим.
- Також доступні Size 30/40/60/100 і група 20/30/40. Якщо чистих ділянок недостатньо, відмова відбувається до вводу. Відмова одного Size не видаляє успішні виміри інших.
- Адаптивний план порівнює звичайну та широку заливку з дофарбуванням. Обидва кандидати зберігають сумарне модельне покриття; вибір враховує рух, зміну Size і форми, групування штрихів. Уже покриті кінці додаткових ліній обрізаються лише в межах безпечного оригінального відрізка.
- Коротка підтверджена Shift-довжина більше не примушує довгу лінію використовувати повільні десятки відрізків. Обирається дешевший маршрут. MaxLength і запас затримки Speed Probe не збільшені й не зменшені.
- Звичайний маршрут зберігає обраний параметр швидкого перенесення. Наявність Speed Probe більше не вимикає його для всіх інших штрихів. Підтверджена лінія не об'єднується зі звичайним маршрутом.
- Для швидкого перенесення близькі штрихи можуть з'єднуватись двома прямими з поворотом. Сумарний перехід — не більше 32 px; кожна точка перевіряється за повною можливою маскою всередині того самого кольору. Ліміти пакета і затримки повороту збережено.
- У прев'ю і журналі є результат вибору плану. Нові пояснення перекладені сімома мовами.

Контраст 80, RGB tolerance 12, перетин трьох масок, критерії Speed Probe та аудит не послаблені. Геометричний примітив лишився під перевіркою дванадцяти заморожених сценаріїв beta.50. Пауза, STOP і механізм RESUME не перероблялися.

Обмеження: вибір дешевшого плану не гарантує, що Adaptive завжди швидший за звичайний Size 3. Додаткове безпечне покриття теж коштує часу, а вузькі або нестабільні відбитки обмежують виграш. Нові Size потрібно виміряти в Rust. Модельне покриття не є підтвердженням фізичного результату.

Release-збірка beta.55: 0 warnings / 0 errors. Офлайн пройшли 423 тести Core та 149 перевірок WPF; живого прогону немає. Pixora.exe і ввід у Rust не запускалися; `inGameTest=false`. Для старого checkpoint потрібен новий START: версія планувальника змінилася. Виміряні пензлі та Speed Probe можуть лишатися актуальними за тієї самої геометрії й DPI. Нового пушу в GitHub немає.
