# CanvasForge C# 1.0 Preview

Перенесення CanvasForge 0.9.8 RC8.4.1 з Python на C# / .NET 8 / WPF.
Це перша збірка для перевірки на Windows 10/11 x64 та в Rust.

## Запуск готової програми

1. Повністю розпакуй `CanvasForge_CSharp_Windows_x64_Preview.zip`.
2. Запусти `CanvasForge.exe` з розпакованої папки. Не винось EXE окремо від DLL.
3. Відкрий редактор картини Rust та перевір захоплені координати.
4. Завантаж зображення й обери кольоровий режим.

Python, .NET SDK та окреме встановлення .NET для готового portable-пакета не потрібні: runtime включено. Ця збірка НЕ Native AOT. Її розмір не відповідає обіцянці «12 МБ».

## Два режими

**Rust Palette / Палітра Rust:** захоплена палітра 4×16 + Quick Colors. Усі кольори мають реальну координату кліку. HEX не вводиться. Auto / 16 / 32 / 64 / 96 обмежує вибір фактично доступними кольорами.

**HEX Direct:** довільні кольори вихідного зображення після кластеризації. Палітра Rust не використовується. Auto / 64 / 96 / 128 / 192 / 256. Спочатку захопи поле HEX і натисни «Тест FF3333». Коди вводяться без `#`, один раз на кольорову групу. Якщо Rust не підтвердить колір після повторних спроб, перенесення зупиниться.

План, preview і worker використовують одні й ті самі RGB та індекси кольорів. Preview на матеріалі Canvas показує збереження ненамальованих ділянок; це не фізична симуляція освітлення та згладжування Rust.

## Інтерфейс і функції

Відтворено темне оформлення, помаранчевий акцент, три сторінки, подвійне preview, пресети якості, розширені картки, палітру плану, START / PAUSE / STOP / RESUME.

Перенесено: імпорт/експорт конфігу, 8 кроків захоплення, ручні області й точки, Quick Colors, форми пензля, Size / Interval / Opacity, нелінійну криву Size з RC8.4, тест HEX, тест controls, вимірювання пензля, українську та англійську мови, прозорість, режими fit/crop/smart, видалення крайового фону, crop об’єкта, blur/median/dither, допомогу відтінкам шкіри й контурам, cleanup областей, H/V групування, Precision coverage, Speed Engine, оцінку часу, прогрес, PNG preview та журнали.

Обробка зображень і малювання виконуються поза UI-потоком. 144 FPS та конкретне споживання пам’яті не виміряно.

## Налаштування

При першому запуску програма шукає старий конфіг у профілі Windows:
- `.canvasforge_v098rc841.json`
- `.canvasforge_v098rc84.json`
- `.canvasforge_v097rc83.json`

Можна імпортувати JSON вручну на сторінці «Налаштування». Старий JSON не перезаписується. Нові файли: `%LOCALAPPDATA%\CanvasForge\config-csharp.json`, `resume-csharp.json`, `session-csharp.jsonl`, `crash.log`.

Перевір координати після зміни роздільної здатності, DPI, положення або розміру вікна Rust. Захоплюй саму доріжку повзунка без назви й числового поля. Форму пензля за потреби задай номером 1–7.

## Керування

- `F6` — пауза / продовження. При втраті фокуса повернись у Rust і натисни F6.
- `ESC` — зупинка.
- `RESUME` — лише для незміненого зображення, плану, координат і налаштувань; Opacity має бути 1.
- При зміні положення/розміру вікна програма зупиняється й потребує повторного захоплення.

Checkpoint зберігається кожні 50 дій і після кольорової групи. Після STOP або збою до 49 уже виконаних дій можуть повторитися; тому RESUME обмежено непрозорими штрихами. Старі Python-checkpoints не імпортуються, оскільки формат плану змінився.

## Перевірка в Rust

Спершу використай невеликий тестовий малюнок:
1. Rust Palette + Safe: перевір кольори, покриття та Quick Colors.
2. HEX Direct + 64/128: перевір тест FF3333, preview і зміни кольорів.
3. Перевір ESC, F6, втрату фокуса й RESUME.
4. Лише потім переходь до великих картинок і Turbo / Max Speed.

Вимірювання пензля малює чотири точки — обери чистий Canvas та контрастний колір.

## Відмінності й межі перевірки

- Стару змішану Adaptive +8/+16/+32 замінено двома незалежними режимами.
- Алгоритми переписано на C#: результат не обіцяється побітово ідентичним Pillow/NumPy.
- Основне компонування відтворено; піксельну тотожність вигляду не перевірено.
- Пройшли 16 автоматичних регресійних перевірок ядра. C# / WPF вихідні файли компілюються.
- Реальний запуск GUI, clipboard/SendInput, різні DPI, вимірювання пензля та поведінка Rust потребують перевірки на Windows. У середовищі збірки немає Windows/Rust.
- ETA — оцінка; реальне приймання вводу грою може бути повільнішим. Гарантій «2–4 дні», «144+ FPS» або «12 МБ» немає.

## Збірка з вихідних файлів

На Windows встанови .NET 8 SDK й запусти `build_windows.bat`. Скрипт перевірить ядро та виконає стандартний `dotnet publish` для self-contained win-x64. Вихідні файли не використовують Python.

Структура: `src/CanvasForge.Core` — зображення, кольори, плани й геометрія; `src/CanvasForge.App` — WPF, захоплення та Windows-ввід; `tests/CanvasForge.Core.Tests` — регресійні перевірки.
