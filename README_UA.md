# Pixora 1.0.14-beta.3

Pixora переносить зображення на картини й таблички в Rust через ігровий редактор малювання. Ця beta-версія призначена для перевірки координат, повзунків і відновлення після паузи на Windows 10/11 x64.

[Зміни версії](CHANGES_1.0.14_UA.md) · [Перевірка у грі та фідбек](TESTING_1.0.14_UA.md)

## Запуск

1. Завантаж артефакт `Pixora_1.0.14-beta.3_Windows_x64` із успішного запуску GitHub Actions.
2. Повністю розпакуй архів і запусти `Pixora.exe` з цієї папки. DLL і файли runtime мають залишатися поруч.
3. Відкрий редактор малювання Rust, завантаж зображення в Pixora та виконай захоплення Canvas, кольорів і повзунків. Повзунок обводь із запасом разом із числом справа; Pixora покаже автоматично знайдені межі зеленим. Enter зберігає результат.
4. Почни з `Stable / Safe / Precision / Opacity 1`, виконай новий START і перевір результат на невеликому зображенні.

Portable-пакет містить .NET runtime. Для готової збірки встановлювати Python чи .NET SDK не потрібно.

## Кольори

**Rust Palette** використовує захоплену палітру й Quick Colors, вибираючи колір кліком. **HEX Direct** використовує RGB із зображення після обмеження кількості кольорів. Для HEX окремо захопи поле вводу, пензель і повзунки та пройди тест HEX перед START.

Preview відтворює план кольорів і покриття. Реальний вигляд у Rust також залежить від матеріалу, освітлення та того, як гра приймає ввід. ETA є оцінкою.

## Керування та координати

- `F6` — пауза/продовження. Після втрати фокуса повернись у Rust і натисни F6.
- `ESC` — зупинка зі збереженням прогресу для RESUME.
- `RESUME` — для сумісного плану та Opacity 1. Мову й опції preview можна змінювати; параметри малювання й координати перевіряються.
- Переміщення Rust **до START** підтримується, якщо DPI та розмір не змінилися і є збережена база координат.
- Зміна DPI або відомого розміру вікна потребує повного повторного захоплення. Переміщення під час перенесення зупиняє його.

Checkpoint зберігається кожні 50 дій і після групи кольору. До 49 вже виконаних дій можуть повторитися після відновлення. Для першого тесту нової beta використовуй новий START; старий checkpoint може бути несумісним.

## Файли

Конфіг, checkpoint і журнали зберігаються в `%LOCALAPPDATA%\Pixora`: `config-csharp.json`, `resume-csharp.json`, `session-csharp.jsonl`, `crash.log`. Наявні файли з `%LOCALAPPDATA%\CanvasForge` переносяться, якщо відповідного файла Pixora ще немає. Перед beta-тестом збережи копію папки Pixora.

Після зміни масштабу ігрового UI виконай нове захоплення. Старий конфіг без бази координат також потребує захоплення. Калібрування пензля малює чотири точки — використовуй чистий Canvas і контрастний колір.

## Збірка

На Windows із .NET 8 SDK запусти `build_windows.bat`: він виконує перевірки ядра та self-contained publish для win-x64. GitHub Actions виконує такі самі перевірки перед створенням portable-артефакту.

Вихідні файли: `src/CanvasForge.Core` — зображення, плани й геометрія; `src/CanvasForge.App` — WPF та Windows-ввід; `tests/CanvasForge.Core.Tests` — регресійні сценарії.
