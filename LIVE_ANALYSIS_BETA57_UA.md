# Межі офлайн-доказів beta.57

Нового живого запуску beta.57 не було. Вхідні дані — надані користувачем зображення, конфігурації й завершені журнали **beta.55** з двох пристроїв. Даних із часом кожної окремої операції немає. Базові плани порівнюються з точним DLL пакета beta.56, а не з припущенням про старий алгоритм.

## Плани

`Testing/Offline_Model_Replay.json` містить вісім пар BVB/FCB/тризуб, Ordinary/Adaptive. Для edge_merge OFF перевірені рівність identity, хешу фізичної маски покриття й числа операцій проти beta.56. Час — оцінка моделі; ці числа не є заміром виконання нового пакета в Rust.

У цих сценаріях ON значно зменшує unplanned, але не завжди скорочує операції. FCB виграє від об’єднання областей; для деяких BVB/тризубів команди додаються, оскільки більша частина цілі стає доступна для підтвердженого пензля. Саме тому в UI є вимкнення, два прев’ю та порівняння Ordinary/Adaptive без автоматичного застосування.

## ETA

`Testing/Recorded_ETA_Baseline.json` оцінює **старі** записані прогнози beta.55. Для чотирьох завершених запусків середня відносна похибка після warmup близько 1,5–2,3%, але максимальна перевищує 8% у трьох із чотирьох запусків. Середній показник не доводить виконання обмеження для кожного моменту.

Новий алгоритм перевірено синтетичним журналом на агрегованих записаних швидкостях: змінні вартості операцій, коефіцієнт ~1,119, накладні витрати, кольорові етапи, warmup, вікно 50. Після 20 операцій похибка ≤8% і діапазон охоплює відомий залишок симуляції. Це не точний replay реальних перехідних затримок. Приймання живого ETA потребує нового журналу beta.57.

## Аудит і колір

Локальні еталони поліпшують розрізнення покриття при неоднорідному освітленні. Біле на незмінному білому не має доказу нанесення фарби та залишається Unknown. Пороги старого аудитора не послаблено, Unknown не стає green чи repair-target.

`palette_cell_proof` підтверджує RGB активного зразка після вибору. Окремі вихідні комірки можуть бути правильні, а застосований колір — ні; саме цей випадок нова перевірка блокує для своєї групи. Сам зразок не є незалежним доказом фізичного RGB результату на полотні.

## UI та пакет

WPF-матриця рендерить сім мов, DPI 96/120/144 і чотири стани без показу вікон/запуску Rust. При pause імітується існуючий worker без виклику native-конструктора. Рендери та JSON-манифест включені в Testing. Це перевіряє композицію й геометрію контролів, не живі координати Windows.

У пакет не включаються приватні конфігурації, сесії, crash/resume журнали. У маніфесті `inGameTest=false`, локальні зміни від бази beta.56, результати тестів і SHA-256 усіх файлів.
