# Тест Pixora beta.24 у Rust

Закрий стару Pixora, розпакуй весь архів в окрему папку, перевір beta.24 у шапці. Для цього пакета потрібен .NET 8 Desktop Runtime x64.

1. У Pixora та Rust вибери однаковий режим Palette / HEX і відповідне калібрування пензля. Сумісне просторове калібрування та Speed Probe v4 не скидаються через beta.24. Якщо залишилися тільки докази beta.21, на чистому полотні виконай просторове калібрування Size 3 і перевір усі шість контролів.
2. Очисти полотно. Запиши новий Speed Probe: обидві незалежні повільні лінії та кандидати 32 / 20 / 12 / 8 мс, які дозволить тест. Старі лінії під новими пробами залишати не можна.
3. Відкрий «Діагностика». Для швидких кандидатів і запасу запиши PASS/FAIL, покриття, переходи, найдовшу сталу серію та частку переходів. Перемкни горизонталь/вертикаль і порівняй показники з PNG лінії. Повільні контролі не мають цієї послідовності зміщень.
4. Стала тонка лінія з однозначним центром має довгу серію; частий зигзаг — коротшу. Широкий підтверджений core може бути неоднозначним, тоді серія обривається. «—» для частки переходів означає відсутні порівнювані пари або старий звіт. 0% не гарантує якість усієї лінії. Жоден із цих показників поки не змінює PASS/FAIL.
5. Перемкни мову Українська / English: обидва нові показники та пояснення tooltip мають перекладатися. У старому beta.23 звіті попередні переходи лишаються, а нові поля показують «—»; beta.22 без траєкторії повідомляє, що її немає.
6. На чистому полотні повтори Four Blocks з параметрами відео beta.21: Experimental 12 мс, packet 16, той самий Canvas, деталізація, adaptive/fast, форма й палітра. Спершу вимкни підтверджений маршрут та аудит для однакового плану. Референс: 150 операцій, 132.56 с активного часу, 112.32 с руху при 45.67 с розрахунку. Збережи кількість операцій, активний час і `motion_group.inputCosts`. `SafetySeconds` перекривається з `ActualWaitSeconds`; додавати їх не можна.
7. Окремим новим START перевір підтверджений маршрут, якщо він отриманий: суцільність, краї, кольори, аудит. Перевір F6/відновлення, STOP/RESUME до завершення, кінцевий час і положення курсора. Це окремі живі перевірки, які не замінюються діагностикою траєкторії.

Надішли відео, `session-csharp.jsonl` та каталоги відповідних запусків `speed-probe` / `coverage-audit` з `%LOCALAPPDATA%/Pixora`. Beta.24 при підготовці пакета в Rust не тестувалася. Старі PNG перевіряються офлайн й не підтверджують швидкі маршрути.
