# Живий тест beta.56

Розпакуй архів у нову папку. Збережені налаштування й відбитки залишаються. Перевір версію beta.56 у заголовку. Перед кожним малюванням очисти полотно й починай новий START.

1. **Палітра Rust.** На тому самому полотні відкрий BVB. Вибери «Палітра Rust», підготуй її й переглянь підсумок плану. Доступна палітра може містити 64 кольори, але зображення використовує лише частину. Порівняй «кольори з командами» з перемиканнями в Rust. У надісланих налаштуваннях BVB очікуються чотири непорожні групи замість десяти. Для інших вимірювань результат може відрізнятися. Pixora не повинна відкривати HEX або створювати нові RGB у режимі палітри.
2. **Пропуски на FCB.** Натисни кнопку меж виміряного пензля в секції плану. Перевір, чи рожеві ділянки відповідають сірим прогалинам у грі. Це прогноз безпечних команд, не успішний аудит. Збережи знімок завершеного результату. Якщо бракує фарби поза модельними пропусками, потрібен окремий аналіз виконання.
3. **Групова швидкість.** Відкрий «Тест швидкості», вибери «Усі виміряні Size» або «3/10/20», натисни «Перевірити швидкість для групи». Актуальні просторові профілі мають використовуватися повторно. На запит повернись у Rust, очисти полотно, потім підтвердь наступний етап у Pixora. Не очищай полотно під час активного тесту. Після кожного Size перевір його збережений маршрут. Відсутність актуального відбитка має бути пояснена, без непідтвердженого прискорення.
4. **Часткова відмова й ESC.** Якщо один Size не пройде, результати попередніх успішних Size мають лишитися. Скасуй групу на наступному запиті: наступний Size не повинен почати малювати. Ручні просторові й швидкісні кнопки доступні окремо. Після повторного просторового тесту Size 3 маршрути Size 10/20 мають залишитися актуальними, якщо контекст не змінився.
5. **Adaptive без зайвих проходів.** На однаковій картинці, полотні, кількості кольорів і деталізації порівняй звичайний та адаптивний режими. Перед START запиши кількість штрихів, модельні пропуски, прибрані/скорочені штрихи та вклад кожного Size. Великі пензлі повинні додавати нове покриття. Дрібний прохід тим самим кольором допускається для ділянок за межами їхнього суцільного ядра. Перекриття не означає, що весь штрих зайвий. Після завершення порівняй реальний час і знімки.
6. **Ввід і результат.** Перевір F6/PAUSE, STOP/ESC і RESUME на поточному checkpoint beta.56. Протестуй HEX окремо від палітри. Якщо ввімкнений аудит, Missing/Unknown мають лишатися відмовою або невизначеністю, а не зеленим «покрито». Перевір перемикання мов у новій секції.

Надішли `session-csharp.jsonl`, `config-csharp.json`, коротке відео групового тесту та знімки результатів. Вони лежать у `%LOCALAPPDATA%\Pixora`; діагностика калібрувань та аудиту — у підпапках цього каталогу. Перед передаванням перевір файли на особисті шляхи й дані.

Ціль тесту — перевірити виконання нової версії. Офлайн-модель збереженого покриття не гарантує фізичної заливки чи прискорення в Rust.
