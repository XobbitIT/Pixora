## Компенсація (заморожена до збору; дані — Row_Calib_1)

- **Старт:** перша команда — центр стовпця a+2. У calib1 старт фарби лежав на −1.93…−2.06 стовпця в 24/24 штрихах.
- **Кінець:** остання команда — центр стовпця b+1. У calib1 недобір становив 0.35 стовпця при X≈934 і 1.17 стовпця при X≈1009. Залежність від місця не розв'язана, тому +1 — компроміс.
- **Вертикаль:** штрих фарбує 2 рядки текселів, тому рядок r малюється лише над стовпцями, де ціль є в r і r+1. У calib1 нижній край був на +1.03 рядка нижче цілі.
- Одиничні рядки цілі й runs, коротші за зсув, відхиляються.
- Ці числа — зсуви для одного контексту й напрямку ліворуч→праворуч, не універсальна константа.

## Оцінка картинок (описова; не змінює вердикт контролів)

- **Тіло:** центр кожного внутрішнього текселя (усі 8 сусідів у цілі) має сильну фарбу.
- **Отвір:** центр кожного текселя отвору на відстані ≥3 від фарби — без змін RGB > 12.
- **Краї з цілі:** для кожного сегмента межі довжиною ≥4 текселі, без кінцевих текселів, позиція краю визначається порогом (bg + inside)/2. Старт для V-країв — на один стовпець усередині фігури.
  - Залишок H: g(edge) − (межа + ψtop/ψbottom).
  - Залишок V: фаза стовпця моделі 0039 − межа.
  - Край виміряний, якщо виміряно ≥ 80% точок; D-події рахуються на суцільних відрізках.
- **Прогнози:**
  - тіло — 0 розривів;
  - отвори — 0 змін;
  - D-події — 0;
  - median |залишку| для H ≤ 0.15 рядка, V-старт ≤ 0.35, V-кінець ≤ 1.0 стовпця.
- **Статуси:** `PREDICTIONS_MET` / `PREDICTIONS_NOT_MET` / `UNMEASURED`.
- **Базова лінія без компенсації** — post-hoc replay тієї ж метрики на кадрах calib1 (`row-picture2-implementation-20261026/replay-calib1-uncompensated.json`):
  - старт −2.01 / −2.02 стовпця;
  - кінець −0.35 / −1.17 стовпця;
  - низ +1.00 / +1.04 рядка;
  - верх 0.02…0.03 рядка;
  - 1 тексель отвору змінено.
