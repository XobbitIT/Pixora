## Правило мітки (заморожене до збору)

- Усі 19 body-перерізів кожної проби обов'язкові; missing/дублікат/порядок/NaN/поза доменом → **INCOMPLETE** до будь-якої арифметики.
- g(y) = S·y/(1 − y/pole). j = round_half_even(median(g(top) − ψtop)).
- Прийняти, лише якщо median|g(top) − ψtop − j| ≤ 0.15 **і** median|g(bottom) − ψbottom − (j+2)| ≤ 0.15. Інакше вся калібровка **INCOMPLETE**, без найближчої мітки й без фільтрації.
- Фільтр: залишити членів, де floor(S·a/(1 − a/pole) + c) + offset = j для **кожної** проби, a = Y + β(Y − 670). Окремо для 1148 та уточненої родини. Порожньо → `MODEL_CONTRADICTED` для цієї родини; обидві порожні → загальний `MODEL_CONTRADICTED`, одна → `MODEL_PARTIALLY_CONTRADICTED`; інакше `CALIBRATED_RESEARCH_NOT_QUALIFIED`.
- Derived-family record (`derived-family-<name>.json`): parentSha, memberIndices, параметри, мітки, evidence SHA, context, policy, protocolId, derivedSha. Заморожується цим review.
- Аудит адресації через Core `TexelGrid` похідної родини: Y 220…1100, одностайний індекс і запас ≥ 0.25, projected edges у [219.5, 1100.5]; rows, longest, supported longest, перший 40-рядковий старт.

## Картинка: описові прогнози (не змінюють статус калібрування)

- **Тіло:** кожна ціла x траси кожного run у її commandY — сильна фарба (спад сірого > 80) у фінальному кадрі картинки проти blank stage-before. Це перевірка об'єднання: сусідні рядки перекриваються, тому розрив одного рядка видно, лише якщо його не закрили сусіди.
- **Краї:** 0 D-подій (|Δ| ≥ 0.3, той самий знак, накопичення ≥ 1.2 px; `StandardTexelAnalysis.Detect`) на 10 краях: outer-top/bottom/left/right, hole-top/bottom/left/right, step-top/left. Позиція краю — субпіксельний поріг (bg + inside)/2, крок назовні від точки всередині фарби; кінці краю (по одному текселю) не вимірюються.
- **Поза резерваціями:** 0 пікселів зі зміною RGB > 12 (збирач відхиляє вже на кожному штриху).
- Статус: `PREDICTIONS_MET` / `PREDICTIONS_NOT_MET` / `UNMEASURED` (якщо хоч одна точка краю не виміряна). Ширина й кінці лише описово; асиметричний старт (~−5 px) не компенсується.
