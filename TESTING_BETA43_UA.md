# Pixora 1.0.14-beta.43 — цільовий живий тест

1. Закрий стару Pixora й розпакуй beta.43 в нову папку. Конфіг не скидай: захоплення й успішні Size 3/10/20 можна залишити.
2. Очисти полотно Rust. Обери саме квадратний пензель, у Pixora — Square, лише Size 1. Запусти окреме автоматичне калібрування в розділі «Пензель».
3. Відкрий діагностику й перевір усі три повтори: окремий локальний еталон, контроль насичення та спільне ядро. Поріг контрасту лишився 80; сусідній слабший піксель не повинен називатись нестабільним еталоном.
4. Якщо Size 1 пройшов: очисти полотно і запусти шість просторових контролів для Size 1. Це окрема перевірка поведінки ліній в інших координатах. Потім, після очищення, тест швидкості.
5. Якщо Size 1 не пройшов: збережи всі три повтори й session-csharp.jsonl. Не повторюй десятки однакових спроб. Залиши підтверджений Size 3 для його маршруту; невдалий Size 1 не слід видавати за точну калібровку.

ESC перериває тест; після переривання очисти полотно. Зміна положення/розміру Rust або DPI вимагає повторного захоплення. Нова версія ще не була протестована в Rust; offline replay останнього запису не доводить стабільності на всіх координатах.
