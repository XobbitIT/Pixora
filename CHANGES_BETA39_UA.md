# Pixora 1.0.14-beta.39 — швидке відображення прев’ю

- Прев’ю показується відразу після побудови зображення, до розрахунків часу для інших профілів. Помилка оцінки часу більше не приховує готовий результат.
- Розрахунок часу використовує окрему незмінну копію калібрування й перевіряє профіль маршруту один раз на форму пензля. Живий ввід і надалі перевіряє поточні вимірювання; критерії калібрування не послаблено.
- Під час обчислення видно «Обчислюю час…», при помилці — «Час недоступний» та пояснення у статусі українською й англійською.
- Помилка числових controls до першого мазка більше не називається помилкою вимірювання Size 1, якщо вибраний інший Size.

Це виправлення швидкості побудови прев’ю, а не прискорення виконання мазків у грі. Усі чотири оцінки часу на записаних даних збігаються з beta.38. Новий живий тест малювання потрібен.
