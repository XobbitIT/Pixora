# Pixora 1.0.14-beta.43 — еталон лише серед сильних пікселів

В останньому Square Size 1 записі beta.42 (07.10.2026, 19:26:32) найсильніші вибрані пікселі мали контраст 81 та 74. Обидва після контрольного нанесення змінились на 0 RGB, але код зарахував тільки один як «стабільний»: він змішував контраст >=80 з перевіркою насичення. Через слабший сусідній піксель справжній сильний еталон отримав FAIL.

## Виправлення

Еталонні пікселі вибираються лише серед тих, що вже мають контраст >=80. Слабші сусіди не стають еталонами й не відхиляють сильний незмінний еталон. Поріг 80, RGB tolerance 12, контроль насичення, перевірка відтінку й перетин трьох масок збережені. Фарба другого нанесення не додається до ядра. Маски не пересуваються за центром плями.

## Доказ і межі

- На реальних before/after/saturation/background crops останньої beta.42 серії три повтори проходять локальну перевірку. Спільне ядро — x=-2, y=2..3 від координати команди: 1×2 екранні px. Це offline replay вимірювань beta.42, а не новий живий PASS beta.43.
- Раніші Square Size 1 серії о 18:52 і 18:56 мають зміщення ядер і порожній перетин. Це виправлення їх не сертифікує. Round Size 1 із контрастом 63–75 також не стає підтвердженим.
- 331 Core та 100 WPF перевірок. Є регресії для останнього запису, напівпрозорого сильного пікселя й контрасту 79. Вбудовані лише невеликі crops полотна, без повного екрану, чату чи журналів користувача.
- Ввід, planner, Speed Probe та audit не змінені. Попередні успішні калібрування не скидаються. Потрібен один новий живий тест Square Size 1; стабільність по всьому полотну ще не доведена.
