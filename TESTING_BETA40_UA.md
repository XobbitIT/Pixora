# Pixora 1.0.14-beta.40 — короткий живий тест ноутбука

1. Закрий попередню Pixora та запусти Pixora.exe з нової розпакованої папки. Перевір beta.40 у заголовку. Конфігурацію обнуляти не потрібно.
2. У Rust відкрий тестове полотно та HEX-палітру. Повтори окремий тест HEX із трьома кольорами. Успіх — усі три підтверджені, без залишеного старого кольору.
3. Запусти окрему перевірку числових полів. Успіх — Size, Interval 0.01 та Opacity 1 підтверджені. Повтори тричі. Якщо зупиниться, запиши назву поля й час; достатньо надіслати свіжий session-csharp.jsonl та config-csharp.json, відео не обов’язкове.
4. Якщо controls пройшли, виконай окреме вимірювання Round Size 3. Успіх controls ще не означає успіх вимірювання пензля — потрібен його власний результат.
5. На чистому полотні намалюй невелике зображення з чотирма суцільними кольорами. Для HEX вибери явно 64 кольори замість Auto; вимкни неперевірене прискорення. Перевір суцільність заливки й завершення прогресу.
6. Тест швидкості виконуй після успішних controls і потрібного калібрування. Попередні проблемні вимірювання не вважати підтвердженими через оновлення версії.

Під час вводу залиш Rust на передньому плані. ESC — зупинка. Після помилки достатньо надіслати текстові логи з ноутбука.
