# Pixora 1.0.14-beta.38 — виправлення після аналізу коду

1. START / RESUME займає операцію ще до асинхронної побудови плану. Повторний запуск не створює другого Painter; STOP скасовує підготовку до будь-якого вводу у Rust.
2. Невдала або скасована побудова більше не залишає старого виконуваного плану. Перед запуском повторно перевіряється відповідність зображенню й налаштуванням; скасований результат не потрапляє у прев'ю.
3. Старе завантаження зображення не може підмінити новіше. Під час завантаження START заблокований; після STOP або закриття пізній результат декодера ігнорується.
4. Окремі функції захоплення, перевірки controls, вимірювання пензля та Speed Probe тепер мають спільний захист від одночасного вводу, STOP і закриття. Загальна перевірка вже мала скасування й зберігає свою послідовність.
5. Відновлення controls після Speed Probe пропускається після скасування/закриття і саме використовує токен STOP. Помилка перед запуском Painter звільняє ресурси й повертає доступ до налаштувань.
6. Після останнього виділення HEX повторно перевіряється геометрія Rust перед збереженням координат. Після окремого захоплення зберігається перебудова прев'ю та вставка зображення.
7. Некоректні старі рядки вимірювання пензля не спричиняють падіння UI. Радіус безпеки й фізична дальність використовують однаковий перевірений парсер; числові рядки читаються незалежно від регіонального формату Windows. Пошкоджений контейнер швидкостей показує невалідний доказ і не дозволяє прискорення.
8. Додані перевірки скасування під час обходу великих областей і проходів distance transform. Відкладені повідомлення старого Painter не змінюють прогрес іншого запуску.

Перевірки: 300 Core / 92 WPF. Нові регресії відтворюють асинхронні конфлікти без керування мишею/клавіатурою гри; чинні тести з проблемними знімками калібрування залишаються в наборі.

Ця версія не змінює критерії прийняття пензля, RGB tolerance, кадрові затримки чи вимоги до трьох підтверджених повторів. Новий живий тест у Rust потрібен. Докладний аналіз: CODE_REVIEW_BETA38_UA.md; інструкція: TESTING_BETA38_UA.md.
