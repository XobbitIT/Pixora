# Pixora beta.53 — підготовка Steam

Локальний набір для підготовки закритого тесту. Реєстрація продукту, оплата, завантаження та публікація не виконувалися.

1. Зареєструвати продукт у Steamworks і отримати справжні AppID та Windows DepotID.
2. Розпакувати окремий `Pixora_1.0.14-beta.53_Steam_Content.zip` у `ContentBuilder/content`. Це виконувані файли, локалізована інструкція та повідомлення про сторонні компоненти, без Source, тестових DLL і журналів користувача.
3. Скопіювати `app_build.vdf.template` до `ContentBuilder/scripts/app_build.vdf`. Замінити APP_ID та DEPOT_ID. Шаблон має `Preview=1`: SteamPipe формує локальний список файлів, без завантаження. Автоматичного SetLive немає.
4. Налаштувати Windows x64 launch option: executable `Pixora.exe`, working directory — корінь встановлення, без аргументів і без вимоги запуску від адміністратора.
5. Перевірити preview за інструкцією SDK. Для справжнього завантаження потрібно свідомо змінити Preview на 0. Пароль та Steam Guard вводяться у SteamCMD користувачем; їх не слід додавати до VDF, архіву або Git.
6. Завантажити збірку, призначити тестову гілку вручну в Steamworks. Доступ тестувальникам видається окремо: пароль гілки сам по собі не дає ліцензію.
7. Встановити продукт через Steam на чистому Windows-профілі й виконати `TESTING_BETA53_UA.md`, включно з реальним малюванням у Rust. Лише після цього заповнити факт живого тесту та подавати продукт на перевірку.

Сторінка продукту: чернетка `Store_Copy.md`. Мови інтерфейсу: українська, англійська, польська, німецька, французька, іспанська, російська. Для п’яти нових мов частина розширеної технічної діагностики поки англійською; не позначати їх як повністю перевірений переклад до мовного бета-тесту.

Системні вимоги, які підтверджує цей пакет: Windows x64, комплектний .NET 8 Desktop Runtime. Rust встановлюється окремо, потрібне відкрите полотно в грі. Мінімальні CPU/RAM/FPS продукту ще потрібно виміряти: не переносити вимоги лише одного ПК на всіх користувачів.

Перед продажем: заповнити реальні реквізити розробника/видавця та адресу підтримки; погодити ліцензію Pixora й умови розповсюдження; перевірити права на маркетингові зображення; додати фінальні графічні матеріали за актуальною таблицею Steam. Цей набір не вигадує юридичних даних, ціну або гарантій роботи гри.

Офіційні довідки: [SteamPipe](https://partner.steamgames.com/doc/sdk/uploading), [тестування](https://partner.steamgames.com/doc/store/testing), [графічні матеріали](https://partner.steamgames.com/doc/store/assets/standard).
