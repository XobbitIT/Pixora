# Pixora — store copy for an international beta

Draft for review. No price, publisher, release date or support address has been invented. New-language UI translations need native-speaker testing; some technical diagnostics currently fall back to English. Rust is required separately. Pixora is an independent application.

## English

**Short description:** Transfer images to Rust canvases with a guided setup, Palette and HEX color selection, live previews and optional measured brush planning.

**About:** Open an image, prepare a clean Rust Canvas, then start painting. Pixora guides the initial selection of regions and checks one working brush. Preview the processed image before transfer. Choose Rust Palette or direct HEX colors. Optional Adaptive brush, Speed Probe and coverage auditing offer more control after calibration. Painting uses mouse and keyboard input; pause with F6 or stop with ESC. Drawing time depends on the image, color count, Canvas size and the responsiveness of Rust. Calibration and a live test are required on your setup.
