# Перевірка beta.60

1. Розпакувати в нову папку. Переконатися, що заголовок beta.60; починати новий план.
2. Відкрити чисте полотно Rust. Повна підготовка з типовим Size 3, окреме вимірювання Size 2. Size 1 відсутній у робочих списках.
3. Перевірити Palette та HEX: кожен наступний колір застосований перед мазками; картинка не містить сторонніх смуг.
4. Намалювати чотири кольорові блоки стабільним Size 3, після цього окремим підтвердженим Size 2. Записати час і фінальний фізичний аудит.
5. Pause/Resume/Stop: припинення вводу, продовження з тієї ж операції; не продовжувати checkpoint старої версії.
6. Порівняти звичайний і Adaptive на тому самому зображенні й параметрах. Порахувати операції, повторне покриття й фактичний час.
7. Дофарбування без придатної виміряної маски має дати діагностику, не перейти до Size 1. Відсутність спільного ядра Size 2 не може стати успішним калібруванням.

Завершений лічильник операцій не є доказом 100% фізичного покриття. Висновки живого тесту — в окремому звіті.
