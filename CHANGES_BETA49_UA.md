# Pixora 1.0.14-beta.49 — витрати виконання та ETA

Локальна Release-збірка. 375 Core / 118 WPF перевірок пройдено; 0 warnings / 0 errors. Pixora.exe та ввід у живий Rust не запускалися. Пушу GitHub для цього пакета немає.

## Що виправлено

- Виконавець зберігає приватну незмінну копію налаштувань. Калібрування кожної використаної форми перевіряється тим самим валідатором один раз і повторно використовується для вибору маршруту та оцінки його вартості. Раніше JSON, відбитки, просторові докази та контекст калібрування повторно оброблялися кілька разів на штрих.
- Редаговані налаштування не мають спільного кеша. Новий START/RESUME створює нового виконавця і перевіряє нову копію доказів. Зіпсоване чи неактуальне калібрування не стає дозволеним маршрутом. Поточні перевірки фокуса, ESC/F6, DPI та геометрії вікна Rust збережені.
- ETA після 20 завершених операцій додає виміряні витрати між штрихами за останніми 50 успішними циклами. Враховуються вибір маршруту, оновлення моделі часу, оцінка, checkpoint та повідомлення прогресу. Час самого Draw рахується окремо, зберігаючи пропорції довгих і коротких штрихів. Зміни кольору/Size/форми, аудит, паузи та повторне встановлення controls не додаються вдруге.
- У підказці ETA пояснено джерело оцінки. Для поточного робочого Size показуються підтверджені H/V маршрути, безпечна затримка і реально перевірена довжина. Штрихи коротші за 8 px лишаються на звичайному маршруті; довгі калібровані лінії діляться за довжиною, підтвердженою Probe.

## Що збережено

Контраст 80, tolerance 12, маски пензля, planner, формули руху, критерії Probe, аудит, HEX-перевірка, кількість кольорів та правила групування не змінені. Для однакових вхідних даних тести перевіряють однаковий маршрут, оцінку руху, послідовність input-команд та затримки. Робочий Size 3 і окремий Size 1 для Adaptive з beta.48 збережені.

## Чого очікувати від швидкості

У звіті ноутбука: 66 439 штрихів, 256 підтверджених HEX-кольорів і близько 1 год 58 хв роботи. Запитані очікування вводу вже складали 5 253 с, фактичні — 5 310 с (близько 88,5 хв). Ще 827 с були всередині Draw поза очікуваннями і 657 с — у групах поза Draw. Цей пакет скорочує повторну обробку калібрування і вимірює решту витрат, але не скасовує ці очікування.

Офлайн-мікровимір на цьому ПК для 256 операцій: старий шлях обробки доказів — 294,9741 мс / 208 853 136 байтів алокацій; новий — 0,962 мс / 305 152 байти. Це вимір лише повторної обробки калібрування, після початкової перевірки. Він не є прискоренням усього малювання в Rust. Окремого таймінгового порога в тестах немає; перевіряються еквівалентність команд і зменшення алокацій.

Відтворення похибки ETA: пропущені 9,89 мс на кожну з приблизно 33 тисяч залишкових операцій дають близько 5,5 хв заниження. Нова модель додає виміряні витрати конкретного запуску; після оптимізації вони можуть бути меншими. Початкова оцінка до 20 операцій залишається попередньою. Майбутні повторні спроби, втрата фокуса чи дофарбування можуть подовжити запуск.

## Нові дані журналу

`eta_update.revision = rolling-timing-v2-operation-overhead`; `estimate.OperationOverheadMs` і `OperationOverheadSamples` — середні витрати між операціями та число зразків.

`motion_group`: `operationOverheadSeconds`, `resolutionSeconds`, `estimateSeconds`, `etaModelSeconds`, `checkpointSeconds`, `reportSeconds`, `routes`, `shiftParts`, `lengthHistogram`, `lengthHistogramRanges`, `executionRevision`.

Лічильники вкладені: `resolutionSeconds` входить у `motionSeconds`; `estimateSeconds`, `etaModelSeconds`, `checkpointSeconds`, `reportSeconds` входять у `operationOverheadSeconds`. Їх не можна підсумовувати як незалежні часи. `motionSeconds + operationOverheadSeconds` описує успішні цикли штрихів без окремо виміряних controls, кольорів та аудиту. Перервані спроби не навчають ETA.

## Межа підтвердження

Живий тест цього релізу ще потрібний. Фактичне скорочення двогодинного запуску, похибку ETA і вигляд у Rust можна підтвердити лише повторенням того самого плану на тому самому ноутбуці. Послаблення затримок без нового Probe або зменшення кольорів не використані як приховане прискорення.
