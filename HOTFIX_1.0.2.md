CanvasForge 1.0.2 Preview

Розпакуй усю папку і запусти CanvasForge.exe.
Спочатку повтори тест HEX; для малювання використовуй START на чистому полотні, а не RESUME старого запуску.

Зміни: виділення HEX End/Shift+Home без очищення кожного символу; визначення зелених смуг повзунків без підписів; довші натискання і паузи між штрихами для обробки грою; логування кожної групи кольорів та цілей повзунків.
Малювання повільніше; попередня оцінка часу може бути заниженою.
Перевірено: збірка C#, 16 тестів ядра, визначення меж повзунків на кадрі наданого відео. Реальне введення в Rust тут перевірити неможливо.
