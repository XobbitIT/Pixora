# Pixora 1.0.14-beta.22

Виправлення за записаним тестом beta.21 від 05.10.2026.

- Speed Probe використовує заздалегідь зафіксований цілий діапазон між мінімальним і максимальним зміщеннями шести просторових контролів. Проміжне −1 px у діапазоні −4…0 не спричиняє помилку лише через відсутність у вибірці. Незалежний повільний контроль, повна ширина ядра, усі поздовжні зрізи, RGB та перевірка сцени залишаються обов’язковими. Швидкі проби не розширюють модель. Старі докази не переходять у новий контекст автоматично.
- Очікування вводу виконуються через high-resolution waitable timer із коротким завершальним очікуванням і перевірками скасування / фокусу. Якщо Windows не надає таймер, зберігається Sleep fallback. Налаштовані затримки руху, захист controls/HEX, кандидати проб і запас не зменшені. Дескриптор таймера закривається після роботи.
- До журналу додано фактичні витрати очікування, перевірок безпеки та SendInput. Втрата фокусу й F6 мають окремі причини.
- Перед зміною controls та вибором кольору калібрування перевіряється геометрія трьох доріжок. За підтвердженого іншого захопленого layout повідомлення пояснює невідповідність Palette / HEX. Автоматичного перемикання чи вгадування режиму немає.
- Кінцевий час у UI — активна тривалість запуску, а не нульовий залишок. Рідкісні Size з 1–4 локальними спостереженнями після загального прогріву поступово уточнюють власний прогноз; статус залишається «Частково виміряно». Чужий маршрут не підставляється.
- Pixora за замовчуванням лишається згорнутою після успіху. Повернення вікна можна ввімкнути в налаштуваннях; помилки й скасування повертають його для пояснення. Повернення курсора до останнього штриха з beta.20 збережено.
- Включено підготовлені відносні показники у порівнянні HEX-палітр: операції / кольори / час у %, Size / широкі операції / ΔE — абсолютна різниця відносно 256. Це прогноз планувальника.
- Нові повідомлення та опції перекладені українською й англійською.

Квантування, планувальник адаптивних штрихів, групування кольорів, правила аудиту та схема checkpoint не змінені. Speed Probe має нову ревізію `probe-spatial-envelope-v4`; потрібні нове просторове калібрування, Speed Probe та START.

Перевірка включає тести повного / неповного ядра, зміщення всередині й за межами діапазону, локальний таймер без ігрового вводу, WPF UI обома мовами та повторний аналіз записаних PNG. Це не новий живий тест Rust і не підтвердження швидких маршрутів.
