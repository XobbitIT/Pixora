# Один сценарій: окремі проходи Standard

Збірка: `1.0.14-rc.8+local-track-increment-4`.

Запускай **Run_Track_Pair.cmd** з нової розпакованої папки. Це два
короткі запуски по30 штрихів: H13, V19, V12 по10 проходів кожен.
Малювання використовує Round/Size3 та збережений Canvas.

1. Закрий інші Pixora. У Rust залиш той самий редактор, вікно й масштаб.
   Interval=0.01, Opacity=1.00 — ручні передумови, Pixora їх не зчитує.
2. Очисти Canvas **червоним кошиком**. Натисни Enter у сценарії
   та повернися в Rust за10 секунд. Почнеться контроль без зсуву.
3. Після повідомлення про зібрані дані натисни OK. Знову очисти Canvas
   червоним кошиком. Геометрію й гру не змінюй і не перезапускай.
4. Повернися до сценарію, натисни Enter та знову перейди в Rust за10 секунд.
   Виконається зміщений варіант з тієї самої збірки, теж30 штрихів.
5. Збережи всю нову папку **Track_Pairs/дата-ID/**. У ній control,
   shifted та source. Знімки й траси записуються автоматично.

Після кожної доріжки буде пауза для native-знімків. Це очікувана частина
збору, а не оцінка швидкості звичайного малювання. Сценарій не очищає
полотно самостійно. Якщо перший запуск зупиниться, другий не почнеться.
Перервані дані зберігаються; продовження або повтор у тій самій папці
не виконується. Кожен новий ручний запуск створює нову папку.

Цей сценарій встановлює, **на якій доріжці з'являється нерівний край**.
Завершення60 команд ще не означає, що фізичну нерівність виправлено.
