# Pixora 1.0.14-beta.53 — тест міжнародного запуску

Спершу розпакуй весь архів у нову папку. Для справді першого запуску використовуй окремий Windows-профіль або резервну копію конфігурації; видаляти робочі налаштування не потрібно. Не переносити калібрування іншого ПК.

1. **Перший запуск.** Видно три кроки: зображення, підготовка Rust, малювання. «Перейти до підготовки» відкриває сторінку, без самостійного тесту в грі. «Як почати» відкриває інструкцію повторно.
2. **Мови.** Перемкни всі сім мов у шапці. Перевір кнопки, пресети, поля, підтвердження та інструкції вибору областей. Після перезапуску зберігається остання мова. Власний шлях файлу, HEX та числові параметри лишаються незмінні.
3. **Вікно.** Перевір звичайний розмір і 900×620, особливо німецьку та французьку. Написи мають переноситися; усе має бути доступне через прокручування. Після відкриття зображення підказка не закриває прев’ю.
4. **Палітра Rust.** Відкрий просте тестове зображення. У Rust відкрий чисте полотно, вибери пензель, натисни підготовку. Пройди виділення та перевірку робочого Size, потім очисти тестові крапки. Повернись у малювання й запусти. Якщо бракує етапу, підказка має пояснити його.
5. **HEX.** Повтори з HEX і 64 кольорами. Перевір, що захоплені поля належать цьому режиму. Перемикання мови не змінює режим, ліміт кольорів, Size або деталізацію. Для невдалого копіювання чисел доступна візуальна перевірка в «Сумісність з Rust».
6. **Пауза/стоп.** F6 призупиняє, продовження відновлює, ESC зупиняє. Мова недоступна під час введення. Додаткові функції — Adaptive, Speed Probe, аудит — перевірити окремо на чистому тестовому полотні.
7. **Чесні результати.** Порівняй прев’ю й результат Rust, час і ETA. Поточний реліз зберігає механіки beta.52; офлайн-тести не підтверджують повноту фарби в грі. Для нового живого прогону запиши версію, режим, кольори, Size, розмір полотна та результат.

Для мовного відгуку: мова → сторінка → точна фраза → бажаний переклад. Частина розширених технічних повідомлень поки англійською. Для помилки додай потрібний фрагмент `%LOCALAPPDATA%/Pixora/session-csharp.jsonl`; перевір особисті шляхи перед передачею. Не надсилати Steam-пароль чи токени.

Steam: встановлення з depot та видача доступу тестувальникам ще не перевірені. Дивись `Source/release/Steam/README_UA.md`. Архів Steam Content — локальна підготовка, а не опублікований продукт.
