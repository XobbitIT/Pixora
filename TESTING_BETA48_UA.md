# Pixora 1.0.14-beta.48 — живий тест Size 3

1. Закрий стару Pixora та розпакуй новий архів в окрему папку. У заголовку має бути beta.48. Стару конфігурацію можна залишити: звичайні значення Size 1 повинні перейти на 3.
2. На сторінці «Малювання» перевір робочий Size 3. У робочому списку, основному калібруванні та тесті швидкості немає Size 1. «Чітко · 1 px» залишається пресетом деталізації, а робочий Size після його натискання має залишитись 3.
3. На ноутбуці обери «Налаштування» → «Повільний ноутбук». У Rust відкрий чисте тестове полотно та інструмент пензля. Натисни «Підготувати до малювання». Очікуй області → кольори → керування → три виміри Size 3. Spatial, Speed Probe і Size 1 не повинні запускатися.
4. Очисти тестові крапки. Відкрий `Testing/Images/Four_Blocks.png` і натисни «Почати». Перевір чотири суцільні області та правильні кольори. Перший прохід — Adaptive й аудит вимкнені. 100% означає виконання команд, а не підтверджене покриття.
5. Повтори на `Testing/Images/Edges.png`: перевір пропуски й товщину тонких ліній. Запиши час, зроби знімок після завершення.
6. Окремо на сторінці «Пензель» можна виміряти Size 10/20. У секції «Адаптивне малювання» має бути кнопка «Перевірити Size 1 для Adaptive». Її натискання тестує лише Size 1 і не змінює звичайний робочий Size 3. Adaptive вмикай тільки після успішного актуального виміру Size 1.
7. Перемкни українську/англійську: робочі списки, окрема кнопка Adaptive й пояснення мають бути перекладені.

За помилки надішли нові `session-csharp.jsonl`, `config-csharp.json` та останню папку `controls-diagnostics` або `brush-calibration`. У цьому релізі живе малювання виконує користувач; офлайн-перевірки не підтверджують його якість у Rust.
