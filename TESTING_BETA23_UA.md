# Тест Pixora beta.23 у Rust

Закрий стару Pixora, розпакуй весь архів в окрему папку, перевір beta.23 у шапці. Потрібен .NET 8 Desktop Runtime x64.

1. Вибери правильний режим Palette / HEX у Pixora та відповідну палітру у Rust. Перевір поточне калібрування пензля.
2. Якщо немає підтвердженого просторового калібрування beta.22/v4, очисти полотно й виконай Size 3 → просторове калібрування → шість повних контролів. Сумісне калібрування beta.22 збережене; повтор через номер beta.23 не потрібний.
3. Очисти полотно знову. Запусти Speed Probe. Запиши обидві незалежні повільні лінії та наступні кандидати 32 / 20 / 12 / 8 мс, якщо контролі проходять. Не малюй проби поверх старих.
4. Відкрий «Діагностика». Для швидких кандидатів і запасу перевір нові поля: основне зміщення, діапазон, переходи, найбільший стрибок, однозначні/неоднозначні перерізи. Збережи PNG та JSON. У повільних контролів залишається їхнє виміряне загальне зміщення; новий аналіз траєкторії стосується просторової перевірки швидких проб.
5. Для одного підтвердженого ядра зміщення може бути однозначним. У ширшого ядра кілька допустимих центрів — нормальна причина неоднозначності. «—» означає недостатньо однозначних даних для порівняння, а не нуль переходів. Велика кількість переходів поки не змінює PASS; її треба порівняти з виглядом лінії й пропусками.
6. На чистому полотні повтори Four Blocks у параметрах відео beta.21: Experimental 12 мс, packet 16, ті самі Canvas, деталізація, adaptive/fast, форма й палітра. Спершу вимкни підтверджений маршрут та аудит для порівняння однакового плану. Запиши кількість операцій і фінальний активний час. Референс: 150 операцій, 132.56 с активного часу, 112.32 с руху при 45.67 с розрахунку.
7. Після запуску порівняй у `motion_group.inputCosts` задані та фактичні очікування, витрати SendInput і перевірок. `SafetySeconds` перекривається з `ActualWaitSeconds` — їх не можна просто додавати. Локальний benchmark Sleep без гри не визначає очікуваний speedup Rust.
8. Окремим новим START увімкни підтверджений маршрут, якщо Speed Probe його отримав. Перевір суцільність, краї, кольори та аудит. Перевір F6/відновлення і STOP/RESUME до завершення, кінцевий час, видимість Rust та курсор біля останнього штриха.

Надішли відео, `session-csharp.jsonl` та відповідні каталоги `speed-probe` / `coverage-audit` з `%LOCALAPPDATA%/Pixora`. Нову beta.23 у грі під час підготовки пакета не тестували.

Деталі перевірок інших функцій з beta.22: [TESTING_BETA22_UA.md](TESTING_BETA22_UA.md).
