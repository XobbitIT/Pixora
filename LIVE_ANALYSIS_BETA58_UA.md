# Аналіз записаного beta.57 тесту 11.10.2026, 16:13–16:35

Джерела: локальний session-csharp.jsonl, config-csharp.json, діагностика і відео Desktop 2026.10.11 - 16.13.03.01.mp4. Це аналіз записаного користувачем тесту; нову beta.58 у грі агент не запускав.

## Підтверджені причини

1. Палітра: три відмови до малювання крапок (16:13:53, 16:14:09, 16:14:56). Старий Size track 455–495, тоді як записаний кадр має Size 359–399, Interval 415–455, Opacity 471–511. Причина не пов’язана зі спроможністю Rust малювати 4 або 16 кольорами. Автопошук на цьому кадрі є офлайн regression fixture без особистих даних.
2. О 16:17–16:19 дві серії по 21 крапці використовували форму 1: контраст лише 8–12/80. Підтвердження суцільного ядра тут правильно відмовило. Для початкової підготовки тепер використовується суцільна форма 3 або 4.
3. Для форми 3 видимі крапки мають контраст 128–161/80, але локальний чорний у верхніх ділянках відображається як 20/26/37. Нейтральна перевірка відтінку відмовляла навіть за стабільності нанесення. Новий шлях вимагає незалежного підтвердження вибраної фарби до й після крапки, а не розширення RGB tolerance. Старий запис не містить цієї пари доказів і заднім числом не називається PASS.
4. О 16:21:34–16:22:06 п’ять Speed Probe спроб відмовили до вводу: не вмістилися 62 ділянки 132 × 132 px. Компактна геометрія перевірена офлайн на реальних розмірах полотна, а Speed Probe критерії не знижені.
5. Повторні відмови окремих Size могли залишати їх старий профіль активним. Тепер підтвердження розмірів, які повторно перевіряються, відкликається на початку транзакції; неповний новий вимір його не повертає.
