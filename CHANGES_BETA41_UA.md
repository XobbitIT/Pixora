# Pixora 1.0.14-beta.41 — незалежний Size і межа рухомого мазка

Автоматична перевірка продовжує просторове калібрування й Speed Probe для нового підтвердженого Size 3/10/20, навіть якщо Size 1 не має стабільного ядра. Перевага надається вибраному `probe_size`; інакше обирається найменший підтверджений Size. Непідтверджений або старий профіль не зараховується як новий успішний результат.

Square fallback виконується лише якщо поточна форма не дала жодного нового придатного Size. Після невдалої або скасованої спроби налаштування форми та попередній контекст повертаються до Round. Після переривання програма не надсилає додатковий ввід у Rust: фактична форма перевіряється й застосовується наступною операцією. Без підтвердженого Size 1 Adaptive й ремонт країв залишаються недоступними.

Три горизонтальні й три вертикальні незалежні повільні контролі тепер вимірюють межу сліду рухомого пензля окремо від ядра. Пошук обмежений наперед поточним радіусом одиночного відбитка плюс чинним лімітом координатного зміщення 4 px. До моделі потрапляє лише зв’язний слід, приєднаний до підтвердженого ядра; обрізані сліди та сторонні зміни відхиляються. Виміряні межі фіксуються до швидких кандидатів і відображаються в діагностиці.

Ці межі не розширюють дозволені зміщення ядра, не змінюють необхідну ширину, RGB tolerance, контраст пензля, критерій 100% або часовий запас. Швидка проба й локальний повільний еталон не можуть навчити нові межі. Новий revision `probe-moving-scene-guard-v8` робить попередні просторові/швидкі докази застарілими. Області, числові поля та вимірювання одиночного пензля зберігаються.

Введення HEX/числових полів beta.40 залишене без змін. Модель RGB повторних крапок, planner, покриття та ремонт у цьому релізі не змінені. Нестабільний Size 1 не оголошується виправленим.

Локально: 314 Core / 98 WPF перевірок. Три збережені пари знімків beta.40 відтворюють старий SceneChanged і перевіряють нове вимірювання без зміни ядра/кольору. Це офлайн перевірка аналізатора, не сертифікація швидкого руху в Rust. Потрібен новий живий тест.
