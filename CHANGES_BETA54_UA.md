# Pixora 1.0.14-beta.54 — підготовка і контроль палітри

Раніше надісланий локальний тестовий ZIP зберігає початковий маніфест до коміту. Код цієї версії підготовлений у гілці PR #2. Живого прогону цієї версії у Rust і публікації у Steam не виконано.

## Що підтвердили останні дані

У запуску beta.53 герба було 12 кольорових груп і 9174 операції. Перші застосовані кольори: `3385FF`, `FFD633`, `FFFFFF`, `3333FF`. У журналі всі вони мали `verified:false`: активний зразок кольору не захоплений. Це не доводить, що Rust застосував неправильний колір, але показує відсутність перевірки.

Оригінальний PNG 250×350 містить 70 RGB-відтінків, включно з антизгладженими краями. Основні: `005BBB` (50824 пікселі), `FFD500` (24979), `FFFFFF` (7272). Білий фон знизу є непрозорими пікселями самого файла. Додаткові відтінки не можна всі назвати помилковими командами програми.

У робочого Size 3 останній вимір не підтвердив стабільне ядро; Size 10/20 мали придатні виміри. Попередня версія все одно дозволяла звичайний запуск із Size 3 без захисту за виміряними масками.

## Зміни

- Одна основна кнопка підготовки на сторінці «Малювання»: області → обраний режим кольорів → керування → пензлі → просторовий тест → швидкість. Окремі дії залишені у відповідних розділах.
- Підготовка вимірює звичайні Size 3/10/20 і вибирає підтверджений робочий розмір. Size 1 не стає обов'язковим.
- Провал необхідного етапу зупиняє підготовку. Провал необов'язкового прискорення не видається за успіх: доступне стабільне малювання, швидкий маршрут не вмикається.
- Спільна модель обов'язкової готовності живить загальний статус, кроки, чіпи та START. Саме числове зчитування більше не дозволяє запускати непідтверджений фізичний пензель.
- Перед кліком палітри двічі перевіряються поточні пікселі комірки й точність її координат. Застаріла комірка зупиняє запуск до кліку; майстер пропонує перезахоплення. Зразок активного кольору, якщо захоплений, перевіряється додатково.
- Точки палітри з вже вирівняних налаштувань не зміщуються вдруге після переміщення вікна Rust; точки готового плану вирівнюються один раз.
- Перевірка комірки явно відокремлена в логах від підтвердження активного кольору й кінцевого RGB на полотні. Без активного зразка останні два **не підтверджені**.
- Ліміти палітри 2/3/4/8 для емблем. Допомога з відтінками шкіри не витісняє основні кольори малих палітр і не резервує відсутні у зображенні відтінки.
- Кольори й якість згорнуті; кроки ведуть до ручного виправлення. Прогрес, тонкий прогрес-бар і ETA видимі внизу на всіх сторінках. Плановий ETA біля запуску. Збережена історія підготовки прив'язана до поточного калібрування; ручне виправлення прибирає старе повідомлення про відмову.
- Номери лишені лише в кроках підготовки. Підказка першого запуску веде безпосередньо до основної кнопки й пояснює необхідність очистити тестові крапки та лінії.

Критерії пензля (контраст 80, RGB 12, перетин масок), приймання Speed Probe, алгоритм виміряних меж і аудит не послаблено. Зміни не гарантують усунення всіх пропусків чи прискорення у Rust без живого тесту.

Підбір палітри отримав нову версію ідентичності: старі контрольні точки малювання палітрою можуть вимагати нового запуску. Історія підготовки та її помилки не змінюють ідентичність малюнка.
