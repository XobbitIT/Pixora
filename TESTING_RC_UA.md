# Pixora 1.0.14-rc.1 — живий тест кандидата

Почни з чистого тестового полотна. Не використовуй старий checkpoint після переходу з beta. Змінюємо кандидат лише за конкретним провалом цього тесту, без нових експериментальних функцій.

1. Розпакуй Runtime ZIP у нову папку. На першому запуску має бути Standard, Size 3, зрозуміла інструкція з трьох кроків. Відкрий невелике зображення з чотирма кольоровими блоками.
2. Натисни «Підготувати до малювання». Перевір захоплення полотна, палітри або HEX, рядка пензлів і трьох повзунків. Для палітри обов’язково виділи лише активний колір у зразку. Standard не має вимагати крапок пензля, Spatial або Speed Probe.
3. Перевір у Rust круглий пензель, Size 3, Interval 0.01, Opacity 1. Запусти малювання. Запиши вигляд, час та пропуски. 100% означає виконані команди; результат оглянь сам.
4. Повтори для звичайної палітри й HEX. У палітрі використовуються тільки доступні кольори. При неправильному активному кольорі програма має зупинитись із причиною, а не пропустити всю картинку та повідомити про успіх.
5. Під час перевірки керування зміни фокус на інше вікно. Має з’явитися пауза й доступне «Продовжити». Повернись у редактор Rust і продовжуй. Підготовка повинна повторити цілий перерваний крок. ESC/STOP у паузі має завершити його без зависання.
6. Під час малювання перевір F6, втрату фокуса, продовження та STOP. Немає ліній до сторонніх вікон; після продовження колір і controls знову перевірені. Після STOP є сумісний checkpoint для Resume.
7. У налаштуваннях натисни «Експорт діагностики». ZIP має містити session/config, поточний source/target, знімки перевірок за наявності та окремий last-run каталог з identity/outcome/settings. Повтори експорт після перезапуску Pixora: історичні й поточні дані мають бути відрізнюваними.
8. Перевір підсумок часу: кольори + штрихи + службовий час + пауза = загальний час запуску. Пауза не входить в активний ETA. На короткій картинці початкова оцінка може уточнюватись; порівняй ETA на 25/50/75% із відео.
9. Перемкни українську, англійську та одну з додаткових мов. Перевір мале/широке вікно, доступність Start/Resume/Stop та навігацію. Standard не має показувати неактивні експериментальні налаштування як обов’язкові.
10. Додатково, на окремому чистому полотні: увімкни «Експериментально», виміряй Size 2/3/10/20 та інші потрібні Size. Тільки підтверджені маски можуть увімкнути Adaptive. Втрата фокуса скасовує неповну пробу; очисти сліди перед Resume. Порівняй Standard й Adaptive на однаковому зображенні — прискорення не гарантоване.

При провалі надішли експорт ZIP, коротке відео, крок зі списку та очікувану/фактичну поведінку. Не продовжуй малювати поверх несправної картинки: новий тест роби на чистому полотні.
