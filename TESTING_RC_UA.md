# Pixora 1.0.14-rc.3 — живий тест

Для пакета **StartFix** спочатку закрий стару Pixora, розпакуй новий ZIP в окрему папку й перевір мітку `local-rc3-startfix` у заголовку. Якщо попередній збій залишив застарілий зразок, «Підготувати до малювання» попросить повторне захоплення областей. Виконай підготовку двічі без переміщення редактора: обидва проходи мають завершитися. START у палітрі та HEX не повинен просити Interval/Opacity. Далі — основний протокол нижче.

1. Розпакуй у нову папку. У Rust відкрий чисте полотно, встанови Interval 0.01 і Opacity 1.00. Після перезапуску редактора перевір, чи збереглись значення.
2. Відкрий Four Blocks. Standard + палітра: «Підготувати до малювання» має запитувати Canvas, палітру, інструмент, форми й Size; без захоплення Interval/Opacity. START має намалювати всі чотири кольори.
3. Сховай активний свотч серверною панеллю, залишивши цільові клітинки видимими. Standard: попередження й продовження; неправильна/зміщена клітинка — зупинка до paint-down.
4. Під час малювання Alt+Tab: release і пауза. Повернення саме до того самого полотна + F6 — продовження. Вийди з редактора без Alt+Tab: ввід має призупинитися. Повтори з меню/смертю/накладкою Steam; запиши відео.
5. Зміни розмір вікна/DPI/режим кольору: має бути запит повторного захоплення. Перевір, що ніякі команди малювання не потрапляють на кнопки біля Canvas.
6. Новий START без першого штриха (ESC у countdown або невдача controls): старий прогрес RC3 зберігається. RC2 config/resume не змінюються. Старий RC2 checkpoint не повинен відновлюватися як RC3.
7. ETA: окремо зафіксуй START, кінець setup, 25/50/75% і завершення. Повтори з тим самим профілем; порівняй діапазон, рух/кольори/service/pause/countdown. Перший запуск без історії не вважати виміряним.
8. HEX: повтори захоплення його панелі, три контрольні кольори та Four Blocks. Відсутній exact HEX proof не дозволяє фарбування.
9. Adaptive — окремо, на чистому полотні. Повтори Size 3 і 10 в різних місцях, збережи before/after/saturation PNG та журнал. Не вимагай автоматичного прийняття видимих точок: контраст 80, tolerance 12 і перетин масок незмінні.

Надішли config-v3.json, resume-v3.json (якщо є), session-csharp.jsonl, failures.jsonl та відповідну папку калібрування. Переглянь знімки на приватні дані перед передаванням. inGameTest оновлюється лише після фактичного тесту нового коду.
